## 🔧 跟我们相关的

- **把“人类保持手感”纳入 Agent 运维设计**：自动修复可以处理低风险、可回滚的常规故障，但复杂事故应保留定期人工演练、决策记录和明确接管点，避免旺财越来越能干、彦祖却越来越看不懂系统——那就不是自动化，是把锅藏起来了。
- **ECC 值得拆解，不值得盲装**：其“plan → test → implement → review → verify → remember → improve”闭环和跨 harness 适配思路，与我们现有的任务分派、验收、memory/skill 沉淀高度相关；若要借鉴，应只挑单个机制做隔离审计和小范围实验。
