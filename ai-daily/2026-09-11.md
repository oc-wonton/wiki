## 🔥 今日头条

- **[OpenAI 发布 Agents API 公测](https://openai.com/index/introducing-the-agents-api/)** — OpenAI 把支撑 Codex 的长任务 Harness、上下文压缩、工具检索、程序化并行调用、子 Agent 编排和沙箱环境封装成统一 API；开发者可选 OpenAI 托管、自有基础设施或 Cloudflare、E2B、Vercel 等合作方环境。这不是又一个薄 Agent SDK，而是在抢占生产级 Agent 运行时层。
- **[DeepSeek 发布 V4.1-Flash](https://x.com/deepseek_ai/status/2097930608790167907)** — DeepSeek 官方称它是新架构家族中最小的模型，原生支持视觉理解，目标是更高能力、更快推理、更高吞吐，并为后续更大模型扩展架构。官方首帖尚未给出足够可独立核验的完整 benchmark，性能结论应等模型卡和第三方实测。

## 📰 行业动态

### 模型 & 研究

- **[Cognition 发布 SWE-2](https://cognition.com/blog/swe-2)**：基于 Kimi K3 做多万亿参数规模 RL 后训练，官方报告 FrontierCode 1.1 Main 得分 50.0%，距 Fable 5.1 不到 1 分且成本低 64%；DeepSWE 1.1 为 73.0%，Terminal-Bench 2.1 为 92.8%。新方法在一次 RL 训练中同时优化不同 reasoning effort 的成本—能力前沿；模型已进入 Devin Desktop 和 CLI。上述数字来自 Cognition 自有或其采用的评测，仍需独立复核。
- ArXiv `cs.AI` 9 月 10 日批次共 150 条；本次未发现同时具备足够影响力、可复现证据和直接行动价值，能压过今日正式产品发布的论文，因此不为凑数收录。

### 产品 & 工具

- **[OpenAI Agents API](https://openai.com/index/introducing-the-agents-api/)** 已面向所有开发者公开测试，使用 API 本身不另收费，只支付模型 token 与工具费用。其关键能力包括跨多个上下文窗口的自动压缩、按需加载工具定义、在代码中并行或链式调用 MCP/函数/内置工具，以及为每个子 Agent 保持独立上下文。
- **[GPT-Live-1 进入 API](https://openai.com/index/introducing-gpt-live-1-in-the-api/)**：采用统一全双工语音模型处理收听与说话，可在对话不中断的同时把深度推理和工具调用委派给 Astra 或第三方后端模型；支持电话场景、长会话、背景噪声和自然打断。前端语音层定价为每分钟 0.05 美元；官方称 Full Duplex Bench 相比 GPT-Realtime-2.1 提升 30 个百分点。
- OpenAI 同日还发布 ChatGPT Work 的 Data Agent 与面向金融机构的 ChatGPT for Financial Services；两者体现其从通用模型向内置数据、权限、审计与行业工作流继续下沉，但对我们当前 Agent 基础设施的直接行动价值低于 Agents API，故不单列正式账本条目。
- Hugging Face 新增 Workflow1111：用 73 个 Gradio Workflow 节点复刻 AUTOMATIC1111 的 11 条媒体管线，并可自动暴露 REST 与 MCP 工具。实现有参考价值，但属于示范性工作流而非底层能力突破，本次不列正式头条。

## 🔧 跟我们相关的

- **优先做 Agents API 对照实验**：拿 OpenClaw 当前一个长任务做 A/B，比较自动压缩、工具检索、子 Agent 隔离、环境托管与失败恢复；记录完成率、人工干预、token、墙钟时间和环境成本。重点不是迁移，而是找出可借鉴或能互操作的运行时设计。
- **把 SWE-2 放入 Coding Agent 候选池而非直接替换默认模型**：用 10 个真实仓库任务对比当前 OMP/Claude/Copilot 路径，单独统计首次有效修改前的步骤数、回归测试质量和每个成功任务成本，验证其“少探索、快动手”是否真的减少返工。
- **语音 Agent 可做一次低成本 Spike**：GPT-Live-1 的前后端解耦方式适合让轻量语音层保持自然交互、把复杂工具任务委派给现有 Agent；先验证中文打断、噪声、电话号码/字母识别和一次完整工具闭环，再考虑产品化。
- **从 Anthropic 威胁报告抽取攻击模式**：后续若官方报告正文可稳定访问，优先映射到 OpenClaw 的工具权限、沙箱、外部内容信任边界和异常调用审计；不要只停留在“模型更安全”的宣传层。
