## 🔥 今日头条

- **[Claude Code 2.1.277 原生支持 `AGENTS.md`](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)** — 当项目没有 `CLAUDE.md` 时，Claude Code 会自动读取 `AGENTS.md` 作为项目指令；这让 OpenClaw、Codex 等已采用的跨 Agent 项目约定可以直接复用，不再需要为 Claude Code 维护一份重复文件。该能力暂未覆盖 Bedrock、Vertex AI 和 Foundry。
- **[PrismML 发布 Ternary Bonsai 2 27B：27B 多模态模型压到 5.9GB](https://prismml.com/news/bonsai-2-27b)** — 新模型基于 Qwen3.8 27B，用三值权重与 FP16 分组缩放实现 1.76 effective bits/weight；官方报告称，在其综合评测中保留全精度基线 98.2% 的能力，同时支持 262K 上下文、图像输入、工具调用和 Apache 2.0 许可。

## 📰 行业动态

### 模型 & 研究

- Bonsai 2 27B 的官方综合分为 83.9，对应全精度 Qwen3.8 27B 的 85.4；分类结果中，coding 为 81.58 对 82.17，agentic/tool calling 为 77.57 对 79.74。这里的“98.2%”是 PrismML 自选评测套件的聚合保留率，仍需独立复测，不能直接理解为所有任务都近乎无损。
- 官方给出的速度为 RTX 5090 最高 143 tokens/s、M5 Max 46.8 tokens/s；模型提供 GGUF 与 MLX 2-bit 权重，可在 NVIDIA GPU 和 Apple 设备运行。当前 Bonsai 2 的 GGUF 需要 PrismML 的 llama.cpp fork，stock llama.cpp 尚不能正确运行其新格式，这一点比宣传数字更影响实际采用。
- ArXiv `cs.AI` 9 月 18 日批次共 215 条；列表页仍只稳定提取论文编号，未用无法核验标题与摘要的条目凑数。HN 热议的 Qwen 3.8 Omni Flash 官方页面正文无法稳定提取，且没有可核验的模型卡，因此本期不据二手标题扩写参数或结论。

### 产品 & 工具

- Claude Code 2.1.277 的 `AGENTS.md` 支持采用明确的 fallback 规则：项目存在 `CLAUDE.md` 时仍以它为准，只有缺失时才读取 `AGENTS.md`；项目指令来源可在 `/config` 的 “Project instructions” 中查看或调整。
- 同一版本还修复了 `claude -p` 与 Agent SDK 在内部错误后可能无结果挂起的问题，现在会报告错误并以 code 1 退出；并修复了复合 Bash 命令中只要一个片段命中 `sandbox.excludedCommands` 就导致整条命令逃逸 sandbox 的边界问题。
- 该版本还把 subagent 结果放入明确标记的独立区块，避免子 Agent 输出伪装成主会话指令；同时清理用户提示中的不可见 Unicode 格式字符，并在发送前展示清理后的文本。这些变化都直接指向多 Agent 系统的指令边界与 prompt-injection 防护。
- Product Hunt Atom feed 已检查；当天候选多为缺少技术证据的产品页，未发现比上述两项更值得推送的增量。

## 🔧 跟我们相关的

- **统一项目指令优先采用 `AGENTS.md`，但暂时保留必要的 `CLAUDE.md` 兼容层。** 对直接使用 Anthropic API 的 Claude Code，2.1.277 已能复用现有 `AGENTS.md`；若还需支持 Bedrock、Vertex AI 或 Foundry，不能立刻删除 `CLAUDE.md`。
- **升级 Claude Code 前后重点验证 headless 失败语义。** 新版本把部分“静默挂起”改成明确的非零退出码，适合我们的自动化 runner，但现有脚本若错误地把无输出当成功，需要同步修正监控与重试条件。
- **Bonsai 2 27B 适合做一次隔离 spike，不宜直接接生产。** 优先在可控机器上验证真实内存、首 token 延迟、工具调用稳定性、中文表现与长上下文退化；同时确认 PrismML fork 的供应链和更新节奏，再评估是否作为 OpenClaw 的本地低敏路由。
