    🤖 AI 日报 — 2026-09-22¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • 小米开源 MiMo-V2.6：1T MoE、原生全模态、百万上下文 — Pro 版为 1.02T 总参数、42B 激活参数，统一处理文本、图像、视频和音频；官方同时开放权重、技术报告、训练环境与 RL 代码，并披露两次生产级 RL 运行的成本和轨迹规模。这不是只发 API 的模型更新，而是一套可研究、可复现的长时 Agent 训练样本。
    • xAI 发布 Grok 4.7 — 新底模与更长 RL 训练重点强化多小时编码和知识工作；API 价格保持每百万输入/输出 token 2/6 美元，官方报告 CursorBench 4.0 从 40.4% 升至 46.3%，并已进入 Cursor、Grok Build、第三方 coding harness 与模型路由平台。

    📰 行业动态¶

    模型 & 研究¶

    • MiMo-V2.6-Pro-RL 采用稀疏 MoE：1.02T 总参数、42B 激活参数，70 层主干，384 个 routed experts、每 token 激活 8 个；原生支持文本、图像、视频和音频，最大上下文 1M token，并使用 5 层 speculative decoder。
    • 小米披露 Flash 与 Pro 各在不到 6 天内完成 30 个 RL step、约 75 万条轨迹，成本分别约 85 万和 262 万美元；训练混合 coding、通用 Agent、视觉和网络安全任务，每步最高处理 35–37 亿 token。官方称 DeepSWE v1.1 从 48.8/58.4 提升到 65.68/72.57，说明大批量混合 Agent RL 的收益不只停留在训练集。
    • 官方模型卡给出的最终成绩中，MiMo-V2.6 Pro 在 DeepSWE v1.1 为 71.9、AutomationBench v1.0.6 为 53.1、OSWorld-Verified 为 82.0；这些仍是厂商报告，需等待独立复测。官方援引 Artificial Analysis v4.3 的 Intelligence Index 46.32，并称其为当时最高分的开放模型。
    • Grok 4.7 使用比 4.6 更大的底模，RL 任务偏向需要数小时的工作，并增强自检和长上下文管理。xAI 报告其 CursorBench 4.0 为 46.3%、DeepSWE v1.1 为 71.0%、Terminal-Bench 4.0 为 38.0%；部分项目仍落后于更贵的前沿模型，因此更值得关注的是性价比而非“全面最强”。

    产品 & 工具¶

    • Hugging Face tokenizers v1 发布候选版 — 在保持与 v0.23 相同 token IDs 和 API 的前提下，重写 BPE 热路径、加入 SIMD splitter、无分配 merge loop、线程本地词缓存与原生并行。官方在 Apple M4 Max 上报告单线程编码提速 3–30 倍，8 workers 达到线性扩展的 76%；Rust 预发布已可安装，Python/C/C++ 等绑定仍在完善。
    • tokenizers v1 对高并发推理和长输入 Agent 更实用：当模型生成速度提高后，CPU tokenization 会逐渐成为喂不满 GPU 的瓶颈。不过当前数字来自项目方 tokbench，且不同 tokenizer family、重复词比例和缓存条件差异很大，接入前应在自己的 prompt/日志分布上复测。

    公司 & 生态¶

    • OpenAI 9 月 21 日成立独立数学与 AI 顾问组，回应数学界对“把开放问题当 benchmark”的担忧。公告称其 8 月 28 日开始训练的内部模型已解决 100 多个长期开放问题；顾问组可公开批评 OpenAI，但不会参与决定内部能力推进节奏。本期把它视为治理信号，不重复报道此前已推送的 Navier–Stokes 结果。

    开源 & 社区¶

    • Google 开源 AX：面向 Agent 工作负载的声明式编排器 — AX 把 Task、Workspace、Gateway、Model 作为核心资源，提供沙箱、网络 egress allowlist、MCP/skills 预热、暂停/恢复和调试入口；CLI 与 manifest 设计刻意接近 Kubernetes，底层基于 Agent Substrate，采用 Apache-2.0。
    • AX 的定位与普通 batch job 不同：它明确处理有状态、长时间等待、突发计算且可能失控烧钱的 Agent。官方宣称单集群可扩展到十亿级任务并可亚秒恢复，但仓库同时标注 v1alpha1、稳定版前可能出现重大 breaking changes；现阶段更适合架构研究和小规模 PoC，不宜直接押生产。
    • Laya：开源、自托管的非自回归 System 1 决策模型 — 仓库于 9 月 18 日创建，四天内增长到约 10.7k stars、879 forks，并连续发布至 v0.3.5。它使用 ModernBERT/mmBERT Encoder 一次并行输出 choice、ordinal score 或二元概率，目标是用几十毫秒的本地推理替代大模型完成分类、路由、风险评分和 guardrail。
    • Laya 的热度值得关注，但不能照单全收其 Benchmark：基础 checkpoint 在 typed-decisions zero-shot 上接近随机且低于多数类基线，0.766 结果来自针对同类 Workflow 的 fine-tune；多语言模型默认也未完成概率校准。更准确的定位是“可用业务数据专门化的高速决策底座”，而不是开箱即用的通用 Agent。
    • GitHub Trending 已检查。trycua/cua 和 ai-memory 属于历史已推送或连续上榜，不重复；BuilderIO/agent-native 虽首次进入当前榜单，但仓库并非本时间窗口内的新发布，未仅因热度入选。AX 使用 google/ax 仓库作为稳定唯一键。
    • Hacker News 今日高热 AI 项包括 MiMo-V2.6、Grok 4.7 与 AX；昨日已推送的 Qwen-Image-2.1 和 ChatGPT 广告像素披露仍在榜，不重复。

    🔧 跟我们相关的¶

    • 优先做 MiMo-V2.6 API 小测，而不是尝试自托管。 1.02T/42B activated 的官方部署示例需要多机多卡；但 API 的 Pro 输出价仅 $0.87/M token，可先用 20–30 个 OpenClaw 真实任务，对比当前模型的工具调用正确率、长任务恢复、视觉输入与总成本。
    • 把 AX 的四资源抽象加入 OpenClaw 架构对照。 Task/Workspace/Gateway/Model 与我们现有 session、sandbox、tool policy、model config 有明显映射；先读设计文档，挑“网络白名单 + suspend/resume”做概念差异表，不急着引入其 Kubernetes/Agent Substrate 全栈。
    • 若有 Rust/Python 高吞吐推理服务，再评估 tokenizers v1 RC。 用真实 OpenClaw 长上下文与工具轨迹跑 v0.23/v1 A/B，至少同时测吞吐、P95 延迟、内存和 token ID 一致性；普通低并发聊天不值得为了理论峰值提前承担 RC 风险。
    • 把 Laya 作为低成本前置路由器做小型评测，而不是直接接生产。 可选 PR 风险分类、Agent 轨迹 needs_review 或日报候选粗筛，使用独立 train/calibration/test 划分，对比规则、gpt-5.6-sol-fast 与 Laya 的 F1、Brier、ECE、P95 和每千次成本。
    • Grok 4.7 已可通过第三方 harness/routers 使用，适合纳入一次价格敏感型 coding eval；先验证真实仓库任务和失败恢复，不按厂商 benchmark 直接替换默认模型。

    💡 一句话观点¶

    今天真正的信号不是又多了两个“最强模型”，而是开放权重、可复现 Agent RL、低价 API 与专用编排基础设施开始同时成熟，竞争正从单次回答转向整条长任务系统。
