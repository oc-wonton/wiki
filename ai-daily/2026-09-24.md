## 📰 行业动态

### 模型 & 研究

- Anthropic 新建了生命科学研究组和自有实验室，把模型训练、海量基因组检索、候选筛选和湿实验验证放进同一团队。Claude agents 汇总约 20 万个 RT、提出 3,500 个新候选系统，再压缩为 20 个深度分析对象；Anthropic 称大部分假设仍会在人工复核阶段被淘汰。
- ART（array-associated reverse transcriptase）主要存在于噬菌体，由逆转录酶、相邻伴侣基因和规则间隔的 DNA 重复阵列组成。Claude 首先从原始序列中注意到这一组合；实验显示该阵列会表达成不同短 RNA，但系统的自然功能仍未知，不能把“形态类似 CRISPR”写成“发现了新 CRISPR 工具”。
- 这项工作最有价值的不是一次性“AI 发现”，而是可量化的人机分工：Agent 负责大规模异常搜索和报告生成，专家负责筛选、实验设计与生化验证。其成本也很高——单轮 2.1 亿 tokens、约 950 个并行 Agent——离普通实验室可复制仍有距离。
- **[UK AISI 与 EvalEval 开放可复核的模型评测记录](https://huggingface.co/blog/evaleval-aisi)** — 新公开的 Evaluation Cards 覆盖 HealthBench、FrontierMath、Humanity's Last Exam、SWE-Bench Pro、Terminal-Bench 2.0 和两项网络安全评测，记录模型、配置、推理预算和方法细节。它再次证明同一模型成绩会随 inference compute、oracle feedback 与协议变化，单个榜单数字不能脱离运行条件比较。

### 产品 & 工具

- **[Claude Code 的 AGENTS.md 支持被发现依赖远程 feature flag](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/)** — 独立研究者在 2.1.277–2.1.280 复现：设置 `DISABLE_TELEMETRY`、`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`，或通过 Bedrock、Vertex、第三方网关使用时，`AGENTS.md` 可能被静默跳过，因为本地文件加载由远程开关 `tengu_agents_md_mod` 控制；Anthropic issue 仍为 open。
- 研究者给出的可靠临时方案是在同目录建立一行 `CLAUDE.md`，内容为 `@AGENTS.md`；共享 skills 则需放进 `.claude/skills` 或使用受控软链接。这里应理解为兼容性绕行，不是 Anthropic 官方修复；使用前仍需以 canary 指令验证实际载入。
- OpenClaw 2026.9.6 的 Gateway/npm 版新增恢复 stranded conversations、Node 重启期间保护活跃任务、远程节点工作区文件/Memory/Skills、后台 session、独立 typed decision model、MCP connector 登录和更完整的 30 天 usage 视图。版本还默认扩大 Tool Search 使用范围，升级前应检查自定义 tool policy 和插件 allowlist。
- 2026.9.6 的 macOS App 问题只影响桌面应用构建，不影响 npm/Gateway 包。官方已把 9.6 从 Sparkle 更新源撤下；已无法启动者需重装 2026.9.5，等待 2026.9.7，而不是反复原地升级。

## 🔧 跟我们相关的

- **Mac 上不要升级 OpenClaw 2026.9.6 App。** Gateway/npm 用户可先在非生产环境验证 9.6 的会话恢复、Tool Search 和插件 allowlist；Mac 桌面端等待 2026.9.7。升级前备份配置并保留可回滚的 2026.9.5 安装包。
- **如果用 Claude Code 读取共享 AGENTS.md，立刻做 canary 验证。** 在测试仓库放一个唯一词，要求模型仅回答该词；若关闭 telemetry、使用企业网关、Bedrock 或 Vertex，优先用 `CLAUDE.md` 的 `@AGENTS.md` 导入，避免以为规则已生效却实际未加载。
- **对 Univer 做一个只读 spike。** 选一份含公式、格式和多 sheet 的工作簿，让 OpenClaw 通过其集成完成读取、改一个单元格、生成预览和回滚；同时记录哪些功能来自 Apache-2.0 OSS、哪些需要 Pro，先证明边界再考虑安装。
- **把“评测协议”提升为模型切换记录的一等字段。** 后续比较 GPT-6、Opus 5.5 或本地模型时，至少保存模型版本、reasoning effort、token 预算、工具集、重试策略、缓存状态和 harness commit，避免把协议变化误判为模型能力变化。
