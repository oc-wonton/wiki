## 📰 行业动态

### 模型 & 研究

- **Ember-1 把“少想一点”变成训练目标，而不是推理参数。** Fireworks 表示，直接降低 Kimi K3 的 reasoning effort 会损失质量，于是通过 50 余次训练实验和 200 余次评估，让模型保留有效反思、减少冗余循环。其公开数据称：Terminal Bench 2.1 得分 82.0%、比 K3 Max 少约 51.9% token；SWE-bench Verified 为 92.2% 对 93.2%，token 少约 15.5%；两家生产客户 A/B 的总 token 约少 35%–39%。这些结果说明“推理 token 效率”正在成为 Agent 模型的独立优化轴，但目前证据主要来自厂商自测与两家未具名客户。

## 🔧 跟我们相关的

- **先做 Ember-1 小样本对照，不直接迁移。** 挑 20 个真实 OpenClaw/编码 Agent 任务，对比 Kimi K3 与 Ember-1 的任务成功率、总 token、总成本、耗时和失败重试数；只有在成功率不降且总成本显著下降时再扩大流量。
- **OpenRig 值得读设计，不建议立刻安装。** 它的稳定 seat、队列、快照恢复和独立 review 与我们的多 Agent 协作高度相关；先借鉴其工作流与恢复设计。若要实测，只在一次性环境运行 `rig setup --dry-run`，逐项审查其对 provider hooks、trust、tmux 和工作区配置的写入。
