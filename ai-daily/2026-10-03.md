## 🔥 今日头条

- **OpenAI 发布 GPT-6 系列生产指南，把长任务的 steering、异步工具和多 Agent 委派正式写进推荐架构。** 指南建议按任务选择 Astra、6.1 Sol 或 Luna，并将 prompt caching、compaction、mid-turn steering、async tool calling、computer use 和多 Agent beta 组合成生产工作流；其中缓存输入最高可便宜 95%，但这是计费能力上限，不等于端到端任务成本会同比下降。[OpenAI 官方指南](https://openai.com/index/practical-guide-building-gpt-6/)
- **ServiceNow 开源 AutoSynthData 方法：从 Agent 失败中生成可执行、可验证的训练任务。** 它用目标模型失败与强教师成功提炼 capability card，再生成任务、环境状态、参考轨迹和 verifier；在 EnterpriseOps Gym 的 Hybrid 实验中，2,000 条合成样本让 Gemma-4-26B-A4B-it 的 mean Pass@1 提升 7.2 个百分点（相对 +35%）。结果只覆盖两个受控企业环境，尚不能外推为通用 Agent 提升。[Hugging Face / ServiceNow](https://huggingface.co/blog/ServiceNow-AI/autosynthdata)

## 📰 行业动态

### 模型 & 研究

- **Ai2 开源 AstaBrief 8B 与训练数据，面向带引用的科研报告生成。** 模型基于 Qwen3-8B，以 47K SFT 样本和约 6K DPO 样本训练；在 Asta 端到端流程中，Fast mode 平均 51.1 秒，Claude 驱动的 Thinking mode 为 178.5 秒。Ai2 明确提示主要训练与评测完成于 2025 年、未对当前前沿模型重跑；14 问人类研究样本也很小，因此更适合作为可本地部署的科研 RAG 基线，而非新的通用 SOTA 结论。[Ai2 / Hugging Face](https://huggingface.co/blog/allenai/astabrief)
- **AutoSynthData 的关键不是“多造数据”，而是把 verifier 作为训练数据的一部分。** 每个候选任务必须满足可执行、参考轨迹能通过、错误结果会被拒绝，并经过有限修复；Hybrid 环境从 63.01% verifier success 提升到 68.55%，ITSM 的 mean Pass@1 从 18.77% 提升到 27.18%。教师依赖、环境模拟偏差和 verifier 漏洞仍是主要风险。

### 开源 & 社区

- **[antirez/ds4](https://github.com/antirez/ds4)** — Redis 作者 Salvatore Sanfilippo 的窄模型本地推理引擎，支持 DeepSeek V4/V4.1、GLM 5.x、Qwen3.8，覆盖 Metal、CUDA、ROCm，并提供 OpenAI/Anthropic 风格 API、本地 coding agent、磁盘 KV cache 和 SSD streaming。仓库约 22.9K stars、2.2K forks，MIT；Hacker News 约 140 points / 36 comments。主要风险：官方明确标注 beta、变化很快、无正式 GitHub release，硬件门槛通常是 96–128GB 统一内存或多 GPU，性能数据主要来自项目自测。
- **[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)** — 同时提供“少说废话”的 Agent skill、压缩工具输出的本地代理和应用中间件；仓库约 109K stars、6.3K forks，Apache-2.0，`v3.0.0` 于 9 月 30 日发布，今日首次被本日报观察到 GitHub Trending。项目公开了失败行和局限，但其 33.2% input token 降幅来自作者维护的 54-run suite，原始 harness artifacts 尚未公开；默认遥测为 opt-out，需先审计再试。
- 新锐与成熟度对照：ds4 是高讨论、无 release 的 beta 新锐，价值在“专用窄引擎 + 本地 Agent API”；Caveman 已有稳定中间件、3.0 release 和第三方 JetBrains/Adobe 证据，但核心代理 benchmark 仍含作者自测。两者都值得阅读，均不建议直接接入生产凭据或关键代码库。
- GitHub Trending 中 `DietrichGebert/ponytail`、`pbakaus/impeccable`、`heygen-com/hyperframes`、`google/skills`、`Panniantong/Agent-Reach`、`colbymchenry/codegraph`、`NVIDIA/OpenShell`、`mvschwarz/openrig`、`mksglu/context-mode`、`obra/superpowers` 等均已出现在历史日报或账本中；即使当日热度高或发布小版本，也不因连续上榜重复推送。

## 🔧 跟我们相关的

- **把 OpenAI 指南转成 provider-agnostic 验收项。** 为 OpenClaw 长任务检查：独立工作是否并行、异步工具完成前是否阻止依赖步骤、steering 是否保留已完成动作、compaction 后是否保留任务状态、子 Agent 结果是否有可追踪证据。
- **借鉴 AutoSynthData 做“小而真”的失败回放集。** 从 OpenClaw 的真实失败中抽取 20–50 个可重放任务，为每个任务写确定性或半确定性 verifier；先比较 prompt/skill 修复，再考虑微调，避免用不可验证的合成任务制造虚假提升。
- **ds4 只做隔离 spike。** 若有 128GB Mac 或 DGX/多 GPU，再用公开模型、无真实凭据的临时环境验证 OpenAI-compatible API、长上下文 KV 恢复、tool calling 与吞吐；没有合适硬件就不为热点专门采购。
- **Caveman 先跑 A/B，不全局安装。** 选一个无敏感数据的代码任务，对比直接运行与代理运行的成功率、总成本、残留上下文和失败恢复；关闭遥测，并检查压缩后能否逐字取回原始输出。
