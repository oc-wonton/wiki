    🤖 AI 日报 — 2026-10-04¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Aleph Alpha 开源英德双语 MoE 模型 Kolibri：78B 总参数、约 3.46B 激活参数、最长 1M context，Apache-2.0 权重可下载。 官方称模型以 768 张 B200 训练，预训练与中训练合计接近 24T tokens，重点覆盖德语、工具调用、长上下文和受监管行业本地部署；公开表格显示多项数学与 Agent benchmark 具竞争力，但主要结果来自厂商自评，1M context 也高于其公开说明的 256K 最长训练长度，仍需独立验证。Aleph Alpha 官方发布
    • Microsoft 与 Hugging Face 发布 ThinkingBox-Bench，要求 Agent 不只“说完成”，还要留下正确数据库状态，并连续 20 次做到。 507 个有状态业务任务、18 个模型的结果显示：79,853 次失败中有 67.24% 仍正常结束且报告无最终工具错误；Claude Opus 5.5 的 pass@1 为 67.16%，但只有 47.53% 的任务能 20/20 全部通过。它把 Agent 验收从文字与合法 tool call 推进到终态、副作用与重复可靠性。Microsoft / Hugging Face

    📰 行业动态¶

    模型 & 研究¶

    • Kolibri 将“主权模型”做成可下载权重而非纯托管口号。 模型含 384 个 experts、每 token 激活 6 个，英德知识截止到 2026-06-18；训练数据约 62% 英文、21.3% 德文、14% 代码，并提供 none/low/medium/high 四档推理强度。风险是其 Pareto、垂直行业和 abstention 结果大多由 Aleph Alpha 自己定义或评估，不能直接当作生产选型结论。
    • ThinkingBox 暴露了 pass@1 掩盖的可靠性鸿沟。 Kimi-K3 的 pass@1 为 57.37%，且至少一次能解 93.89% 的任务，但只有 13.41% 的任务能连续 20 次全部成功；GPT-6 Astra、Claude Opus 5.5/5 分别保留约 78%、71%、71% 的单次成功率。约四分之五失败被归为工具处理问题，说明重试、前置条件、空查询和终态校验往往比“换更聪明模型”更先该修。
    • ArXiv cs.AI 最新仍是 10 月 2 日批次；列表页本次未可靠提取论文标题，没有以不可核验条目凑数。

    产品 & 工具¶

    • Claude 发布 Opus 5.5 长任务实用指南。 建议一次给完整任务与完成标准、删掉“think carefully”式提示、长任务用文件保存 checklist、只在真正阻塞或破坏性操作前停下，并要求 subagent 结果带证据；同时明确 flagged message 可能切换到旧模型，用户可配置为切换前先询问。Claude 官方指南
    • addyosmani/agent-skills 0.6.12 修复了两类危险的 skill 错误。 spec-driven-development 现在写完 spec 后强制停下等待批准；发布清单删除了并不存在的 npx prisma migrate rollback，另修复不可解析的 JavaScript 示例并强化 reference anchor 校验。该仓库已是历史项目，本次只因真实 release 增量报道，不按 Trending 热度重复推送。0.6.12 release
    • Anthropic News 最新仍为 9 月 22 日 Claude Opus 5.5；Anthropic Engineering 未出现窗口内新文章；claude.com/blog 页面正文无法完整提取，但通过 Claude 官方独立文章与 HN 高热条目核验了上述 Opus 5.5 指南。OpenAI 最新仍为 10 月 2 日 GPT-6 指南，Google AI 列表未发现窗口内可核验增量。

    公司 & 融资¶

    开源 & 社区¶

    • microsoft/thinkingbox — 用 MCP 工具环境、隔离状态、终态与副作用检查来评测或训练工具型 Agent；MIT，约 85 stars / 10 forks，无正式 GitHub release。配套 thinkingbox-data 和 Hugging Face OpenEnv 适配让 507-task benchmark 可复现，但仓库体量与采用度仍小，完整运行需 Docker、Typesense、模型端点和固定数据版本，成本较高。
    • addyosmani/agent-skills — 25 个生产工程 skill 与跨 Claude Code、Codex、Cursor 等 host 的适配；约 100.8K stars / 10.6K forks，MIT，0.6.12 于 10 月 3 日发布。成熟度较高，但整包安装会扩大 prompt 与行为面，且本次发布后 Oh My Pi / Dojo host guide 又因未实测而撤回，说明仍应挑选、评审、逐个引入。
    • GitHub Trending 今日高热的 DietrichGebert/ponytail（约 +1,281 stars）、Panniantong/Agent-Reach（约 +1,696）、pbakaus/impeccable（约 +699）、affaan-m/ECC、JuliusBrussee/caveman、earendil-works/pi 等均已出现在历史日报或账本；连续上榜不算新增。没有为了满足项目数量而重复旧闻。

    🔧 跟我们相关的¶

    • 把 ThinkingBox 的“终态验收”纳入 OpenClaw 自动化。 对每个会写文件、改配置或操作外部系统的任务，同时检查目标状态、意外副作用和用户可见交付；先挑 10 个真实失败任务，每个重复 5–20 次，记录 pass@1 与全通过率。
    • 审计 skill 要看行为，不只看文字。 优先检查：是否越过批准点、是否引用不存在的命令、示例是否可解析、reference 链接是否真实、失败时是否保留可恢复状态；0.6.12 的修复正好说明高 stars 不等于无行为漏洞。
    • Kolibri 只做隔离评测。 若需要德语、本地部署或欧盟合规候选，再下载 Apache-2.0 权重，以真实德语文档、工具调用和长上下文召回做独立测试；不要直接采用厂商 Pareto 图或 1M context 声明。

    💡 一句话观点¶

    今天真正重要的不是又多了一个高分模型，而是 Agent 工程开始把“做对一次”升级为“留下正确终态、没有额外副作用，而且能稳定重复”。
