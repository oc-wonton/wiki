    🤖 AI 日报 — 2026-10-05¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Strata 把 125B Qwen3.8-Flash-Next 放进 12GB 游戏显卡 + 系统内存，成为今天最值得验证的新锐本地推理项目。 仓库 9 月 24 日创建，当前约 11.1K stars / 972 forks；10 月 4 日 Hacker News 讨论约 597 points / 279 comments。它提供 Windows/Linux 一键安装、OpenAI/Anthropic/Responses 兼容 API 与 MCP 管理面。作者在 RTX 5070 上报告 Q2_0 约 94 tok/s 输出、2,650 tok/s 读取 32K prompt，但数据主要为作者自测，模型需约 35–55GB RAM、约 80GB 磁盘，量化质量与不同硬件稳定性仍待独立验证。GitHub · HN
    • text-to-cad 首次进入本日报观察：把 CAD、工程图、URDF/SRDF/SDF、DFM、切片与打印交付做成 12 个 Agent skills。 仓库约 16.9K stars / 1.7K forks，MIT；10 月 3 日密集发布 v0.7.9–v0.7.11，可装进 Codex、Claude Code、Cursor 等 harness，也提供本地 CAD viewer 与 MCP。它把 Agent 从“生成脚本”推进到可检查 STEP、DXF、机器人描述和制造约束，但依赖本机原生 CAD 栈；Windows Smart App Control 会拦截未签名 OCP 模块，且自动制造文件仍必须人工审图。GitHub

    📰 行业动态¶

    模型 & 研究¶

    • Strata 的亮点不是新模型，而是异构内存调度。 高频 experts 常驻 GPU，其余放在系统内存并由 CPU 并行参与，SSD 保存大型查找表，再用 speculative decoding 加速；这让 125B MoE 在消费级机器可运行。风险同样明确：低比特量化、RAM/SSD 压力、单请求默认并发，以及作者测试条件都可能放大“能跑”和“值得生产使用”的差距。
    • ArXiv cs.AI 最新仍停在 10 月 2 日批次，周末没有新的日期窗口；列表页本次只可靠提取编号、未可靠提取标题，因此没有用不可核验论文凑数。

    产品 & 工具¶

    • Agent 时代需要默认硬预算上限。 Simon Willison 指出，能自主调用 API、部署服务和扩容资源的 Agent 会把意外账单风险放大；软告警不足以阻止失控消耗。AWS 新 Builder Experience 和 Google Cloud 部分服务已提供达到上限后暂停项目的 spend caps，但覆盖面仍有限。对 OpenClaw 一类自动化，预算上限应和权限、超时、速率限制一样成为执行前置条件。原文
    • Anthropic News 最新仍为 9 月 22 日 Claude Opus 5.5；Anthropic Engineering 顶部展示的 containment 文章实际发布于 5 月 25 日，不属于本窗口；Claude Blog 页面正文提取失败，HN 与官方独立页面也未发现比昨日 Opus 5.5 指南更新的可核验文章。OpenAI 最新仍为 10 月 2 日 GPT-6 实践指南；Google AI 列表未提取到窗口内新增；Hugging Face 最新条目仍为昨日已推送的 ThinkingBox。

    公司 & 融资¶

    开源 & 社区¶

    • Niko1221/Strata — 新锐本地推理层；约 11.1K stars / 972 forks，MIT，仓库创建约 11 天即形成高热讨论。优点是消费级 NVIDIA/AMD、统一 API 和 Agent 接入完整；主要风险是早期 0.1.x、作者 benchmark、量化损失及 32–96GB RAM 门槛。
    • earthtojake/text-to-cad — 较成熟的 Agent CAD skill 库；约 16.9K stars / 1.7K forks，MIT，已有连续正式 release。优点是工作流覆盖广且输出面向制造；风险是原生依赖、跨平台安装、遥测选择与制造安全审核。
    • 72 小时观察：calesthio/OpenMontage — 约 63.2K stars / 8.1K forks、AGPL-3.0，把视频研究、脚本、素材、审批、渲染做成 12 条 Agent pipeline；项目规模和演示信号强，但无正式 GitHub release，700+ skill/知识文件、众多外部 provider 和供应链面需要先审计。
    • 72 小时观察：michael-denyer/pstack-claude — 约 1.1K stars / 129 forks、MIT，把 Cursor pstack 工作流移植到 Claude Code、Codex、Pi、OpenCode 与 Gemini；10 月 4 日连发 v0.9.65–0.9.67，但仍是 0.x 移植项目，路由 hook、模型默认值和上游同步质量需验证。
    • GitHub Trending 中 pbakaus/impeccable、DietrichGebert/ponytail、Panniantong/Agent-Reach、addyosmani/agent-skills、thedotmack/claude-mem、antirez/ds4 等均已出现在历史日报或账本；连续上榜不算新增。Product Hunt、36kr 与量子位本次分别被反爬或安全检查阻断，未使用旧缓存冒充今日内容。

    🔧 跟我们相关的¶

    • 先隔离评测 Strata，不直接替换稳定 provider。 用同一组 OpenClaw 路由、工具调用和长上下文任务，对比输出质量、首 token、稳态 tok/s、峰值 RAM/VRAM、32K prompt 读取、崩溃恢复和并发排队；重点确认 Q2/IQ2 量化是否损害工具参数与中文。
    • 给所有可计费 Agent 工具增加三层护栏： provider 侧 hard spend cap、单任务 token/金额预算、网关侧速率与并发上限；任一层达到阈值立即停止，而不是只发告警。
    • text-to-cad 只选单个 skill 做沙盒验证。 优先从工程图或 DFM 检查开始，核对生成文件、测量证据和引用规则；不要整包引入后直接连接打印机或制造服务。

    💡 一句话观点¶

    今天的增量都指向同一件事：Agent 能力正在从“会调用工具”扩展到本地大模型、CAD 和视频生产，但真正决定能否放心放权的，仍是独立验收、硬预算和可控爆炸半径。
