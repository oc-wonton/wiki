## 🔥 今日头条

- **OpenAI 开始把不可见文本水印带进 ChatGPT、Codex 与 API。** API 客户今天起可为部分模型选择开启 textGrain；未来数周，欧盟地区符合条件的 ChatGPT/Codex 文本将默认加入水印，检测器先只向获批研究者和专业机构开放。官方也主动披露局限：在 1% 假阳性目标下，约 200 token 文本检出率约 80%、400 token 约 95%；替换 10% 同义词会把 400-token 样本检出率从约 92% 降到 66%，替换 25% 后仅约 17%。这意味着它适合做来源信号，不能证明作者、所有权、真实性或责任。[官方说明](https://openai.com/index/eu-text-provenance/)
- **Reflection 发布 501B 总参数、23B 激活参数的 Beam 预告，瞄准 Coding 与 Agent 工作负载。** 官方称其使用 23.8T tokens 预训练，并在 10.5K GB300 上进行四周、超过 1 亿条 rollout 的高计算量 RL；权重、技术报告、模型卡和开发者组件计划本月晚些时候发布。当前只有早期访问与厂商自报 benchmark，尚未真正开放权重，因此“open-weight”能力和推理成本要等可复现实测后再判断。[官方文章](https://reflection.ai/blog/introducing-beam)

## 📰 行业动态

### 模型 & 研究

- **Beam 的训练规模本身值得关注，但今天仍是预告而非可下载模型。** 官方报告 DeepSWE v1.1 44.4、Terminal-Bench 2.1 80.1，并强调用 23B 激活参数换取推理效率；这些数字来自厂商评测，且权重、技术报告和模型卡尚未发布。正确姿势是先跟踪 artifact 与第三方复现，不根据预告改生产路由。
- **Claude Opus 5.5 Agent 找到两个室温反铁磁半导体候选。** Vals AI 与研究者称 Agent 设计了尚未合成的 YBaMnFeO₅，并从 1999 年材料中重新识别 KV[Cr(CN)₆]；后者曾实测磁有序到 376K，但带隙和自旋筛选尚未实验测量。团队公开了输入、原始输出、分析代码、复跑和 caveats；这是“可审计的计算候选”，不是已验证材料发现。[研究说明](https://www.vals.ai/blogs/room-temperature-magnetic-semiconductors)
- ArXiv `cs.AI` 10 月 5 日新增 266 篇，但列表页本次未可靠提取标题；没有仅凭编号凑数。

### 产品 & 工具

- **OpenAI 把 ChatGPT 广告扩到图像生成场景。** 新视觉广告本月稍后先在美国测试，广告与生成图像分离并标注；同时接入 Hightouch、Tealium、LiveRamp 及多家归因伙伴传递转化数据。OpenAI 称答案不受广告影响、对话保持私密，但对 Agent 产品而言，广告归因、站外转化回传与“回答独立性”将成为需要持续审计的新边界。[官方说明](https://openai.com/index/new-chatgpt-ads-format-and-measurement/)

### 开源 & 社区

- **[tester-army/e2e](https://github.com/tester-army/e2e)** — 首次观察进入 GitHub Trending，约 4.8K stars / 198 forks，当日约 +1,398 stars；Apache-2.0，10 月 4 日发布 Web 0.12.0。它让自然语言 Agent 执行 Web/移动端流程，再用 locator/assertion 验收，并把已验证动作录制为后续无模型重放。风险是仍在走向 1.0、minor 版本可破坏兼容，CLI 默认发送可关闭的匿名遥测；项目 benchmark 与稳定性仍需独立验证。
- **[pingdotgg/t3code](https://github.com/pingdotgg/t3code)** — 首次观察进入 Trending，约 25.6K stars / 6.6K forks，当日约 +485 stars；MIT，最新 v0.0.45。它用 Web、桌面和手机控制本机 Claude Code、Codex、Cursor、OpenCode 等 Coding Agent，直接命中远程调度需求。主要风险是官方明确标注“very early”、版本仅 0.0.x、远程访问与本机 Agent 权限面很大，且 open issues 超过 2K，不应直接暴露公网。
- **72 小时观察：[calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)** — 约 64.0K stars / 8.1K forks，较昨日约 +812 stars，仍在 Trending；AGPL-3.0、仍无正式 release。高采用度继续成立，但 700+ skill/知识文件和多 provider 供应链面仍需先审计。
- **72 小时观察：[michael-denyer/pstack-claude](https://github.com/michael-denyer/pstack-claude)** — 约 1.4K stars / 152 forks，较昨日约 +280；10 月 5 日发布 v0.9.73。更新频繁且与多种 Coding Agent 直接相关，但仍是 0.x 移植项目，hook 权限和上游同步质量待验证。

## 🔧 跟我们相关的

- **把 OpenAI 水印当“弱来源信号”，不要当事实或责任判定器。** 若后续接入检测 API，日志里必须同时保存文本长度、模型/时间、编辑链和误报阈值；短文本、翻译、同义改写后的阴性结果不能证明是人写的。
- **优先沙盒试跑 tester-army/e2e。** 选一条无破坏性的 OpenClaw Web 流程，对比首次 Agent 探索与录制重放的成功率、模型调用数、页面变更后的恢复能力；先禁用遥测并固定依赖版本。
- **T3 Code 只做隔离评测。** 若验证手机远程调度，限定本机回环或私网、最小权限工作区和人工审批；不要运行一键安装管道或把控制面直接暴露公网。
- Beam 等权重、模型卡与技术报告真正发布后，再用同一套 Coding/Agent 任务和成本指标复测；今天只进入观察，不替换 provider。
