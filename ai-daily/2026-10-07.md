## 🔥 今日头条

- **Mistral 发布 1T 参数、49B 激活的 Mistral Large 4 公测，权重计划月底开放。** ML4 原生多模态，面向 Coding、Agent、网络安全和专业知识工作；API 已可试用，但模型仍在训练和红队阶段，架构细节、后训练方法及权重尚未发布。Mistral 报告 DeepSWE v1.1 61.7%、Terminal-Bench 4 28.3%、AutomationBench 59.9%，多数数字仍来自厂商或厂商委托评测，因此今天应把它视为“值得预约复测的开放权重候选”，不是已验证的生产替代。[官方发布](https://mistral.ai/news/mistral-large-4/)
- **Anthropic 扩大 Cyber Verification Program，用三档验证机制开放更强网络安全能力。** Defense、Red Team、Specialized 三档分别对应防御、授权红队和高风险安全系统测试；Red Team 档在 CyScenarioBench 中不再触发阻断，Opus 5.5 完成 34/50 次任务，与无安全限制时 67.6% 的成功率接近。Anthropic 还称 Glasswing 合作方 4–7 月发现至少 129,000 个已验证漏洞，其中超过 33,000 个为高危或严重，但数据来自部分合作方报告、统计口径不统一，应视为项目方披露而非独立审计。[官方说明](https://www.anthropic.com/news/cyber-verification-program)

## 📰 行业动态

### 模型 & 研究

- **OpenAI 公开一批内部前沿模型生成的数学结果。** 结果以 GitHub 仓库发布，部分证明提供 Lean 形式化，并附 10 份推理摘要、尝试次数和计算量统计；官方称平均每项结果约使用相当于三小时 ChatGPT Pro thinking 的计算。它比只公布 benchmark 更可审计，但论文的数学正确性、引用完整性和重要性仍需数学界逐项复核。[官方说明](https://openai.com/index/sharing-ai-progress-in-mathematics/)
- **Google 发布 EmbeddingGemma 2：740M 参数的端侧多模态 embedding 模型。** 它把文本、代码、图像、视频和音频映射到统一空间，Apache-2.0 开放权重；文本模式可裁到 270M，完整多模态模型在 Pixel 11 Pro 量化后约占 567MB active RAM，支持 8K context 和 Matryoshka 向量截断。官方报告 MTEB Code 从 68.76 提升到 78.68，适合本地代码检索和隐私优先的多模态 RAG，但跨设备延迟、召回率和量化损失仍需按自己的语料验证。[官方发布](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/)
- **Falcon-Emirati-7B 针对阿联酋方言与文化语境做专项适配。** TII 结合真实方言网页、文化语料和受词表约束的合成数据，报告在 1,173 道 Alyah 方言题上达到 84.83%；开放生成的方言忠实度由 Gemini 3.7 Flash 担任评审。它说明“小模型 + 本地方言数据”可胜过更大的通用模型，但 benchmark、训练方和主要评测仍高度同源，不列为今日头条。[技术文章](https://huggingface.co/blog/tiiuae/falcon-emirati)
- ArXiv `cs.AI` 10 月 6 日新增 554 条；列表页本次只稳定提取到编号，未仅凭编号和摘要缺失条目凑数。

### 产品 & 工具

- **OpenAI Decisions API 进入公测，专门做高速分类、路由和评分。** `/v1/decisions` 目前只支持 `gpt-6-luna`，可对文本或图像返回 predicate 概率、固定 choice 分布或 rubric score；官方称速度约为 Responses API 的 10 倍，输入价 $0.10/百万 token、无输出 token 费用。它很适合 Agent 路由和审核队列，但概率不是校准保证，必须用自有标注集设阈值并保留人工兜底。[官方文档](https://developers.openai.com/api/docs/guides/decisions)
- **Claude 进入 Google Docs、Sheets 和 Slides。** 付费 Claude 计划可在 Google Workspace add-on 公测中直接读写当前文件；默认模式逐项审批，另有“接受全部编辑”模式。Sheets 可写公式、透视表和图表并调用 Python 清洗数据；Enterprise 的 CMEK、Compliance API 和 OpenTelemetry 审计仍适用。对自动化而言，真正重要的是编辑审批与 Google 共享权限沿用，不能把“在文档里运行”误当作权限天然安全。[官方文章](https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides)
- OpenAI 与 Atlassian 扩大合作，GPT-6 系列将进入 Rovo 和 Teamwork Graph；3,000 多名 Atlassian 开发者已在使用 Codex。方向值得留意，但今天更直接可试的是 Decisions API 与 Claude Workspace 集成，因此不单列头条。[官方说明](https://openai.com/index/atlassian-partnership/)

### 公司 & 融资

- **Mistral 把 ML4 明确定位为欧洲主权 AI 基础设施。** 模型用欧洲自有数据中心的 3,800 张 Grace Blackwell GPU 训练，并承诺月底发布权重；“开放权重 + 私有部署 + 网络安全能力”是差异化核心。不过权重、许可证、部署成本和真实吞吐均未落地，不能仅凭预告判断可控性。
- Anthropic CVP 的分级开放表明前沿厂商正在从“一刀切拒绝”转向“身份验证 + 用途分层 + 审计留存”；这会提升专业防守能力，也把资格审核、数据保留和责任边界变成产品能力的一部分。

## 🔧 跟我们相关的

- **优先做一个 Decisions API 的离线路由评测。** 用现有任务分类样本测 predicate/choice 的召回率、拒绝率、置信度校准和成本；阈值由误分代价决定，不直接把官方“10 倍速度”当生产结论。
- **给 EmbeddingGemma 2 做本地代码检索小样。** 用一份可公开仓库对比当前 embedding：索引大小、Top-k 命中、中文/代码混合查询、量化后延迟和 RAM；它的 270M 文本模式比完整多模态更适合先跑 MVP。
- **REA 只在授权样本和隔离工作区试跑。** 先用静态 JavaScript/APK fixture 验证 evidence 输出，不运行未知二进制、不自动安装 Hopper/Ghidra、不让 MCP 接触私人项目。
- **Mistral Large 4 等真正开放权重再测。** 先记录 API 预览的 Coding/Agent 成功率和成本，月底权重、许可证、模型卡到位后再比较私有部署；今天不改生产 provider。
- Claude Google Workspace 若要接入，应保留默认逐项审批，并核验 connector 与 Google 文件共享权限、审计日志和撤销路径；“Accept all edits”只用于可恢复副本。

## 💡 一句话观点

> 今天的主线不是单纯“模型更大”，而是能力正在被拆成可部署的部件：开放权重负责主权与可控，高速决策模型负责路由，端侧 embedding 负责私密检索，分级验证负责高风险权限；下一阶段的竞争会落在这些部件能否被安全地拼起来。
