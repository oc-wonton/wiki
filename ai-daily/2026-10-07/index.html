    🤖 AI 日报 — 2026-10-07¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Mistral 发布 1T 参数、49B 激活的 Mistral Large 4 公测，权重计划月底开放。 ML4 原生多模态，面向 Coding、Agent、网络安全和专业知识工作；API 已可试用，但模型仍在训练和红队阶段，架构细节、后训练方法及权重尚未发布。Mistral 报告 DeepSWE v1.1 61.7%、Terminal-Bench 4 28.3%、AutomationBench 59.9%，多数数字仍来自厂商或厂商委托评测，因此今天应把它视为“值得预约复测的开放权重候选”，不是已验证的生产替代。官方发布
    • Anthropic 扩大 Cyber Verification Program，用三档验证机制开放更强网络安全能力。 Defense、Red Team、Specialized 三档分别对应防御、授权红队和高风险安全系统测试；Red Team 档在 CyScenarioBench 中不再触发阻断，Opus 5.5 完成 34/50 次任务，与无安全限制时 67.6% 的成功率接近。Anthropic 还称 Glasswing 合作方 4–7 月发现至少 129,000 个已验证漏洞，其中超过 33,000 个为高危或严重，但数据来自部分合作方报告、统计口径不统一，应视为项目方披露而非独立审计。官方说明

    📰 行业动态¶

    模型 & 研究¶

    • OpenAI 公开一批内部前沿模型生成的数学结果。 结果以 GitHub 仓库发布，部分证明提供 Lean 形式化，并附 10 份推理摘要、尝试次数和计算量统计；官方称平均每项结果约使用相当于三小时 ChatGPT Pro thinking 的计算。它比只公布 benchmark 更可审计，但论文的数学正确性、引用完整性和重要性仍需数学界逐项复核。官方说明
    • Google 发布 EmbeddingGemma 2：740M 参数的端侧多模态 embedding 模型。 它把文本、代码、图像、视频和音频映射到统一空间，Apache-2.0 开放权重；文本模式可裁到 270M，完整多模态模型在 Pixel 11 Pro 量化后约占 567MB active RAM，支持 8K context 和 Matryoshka 向量截断。官方报告 MTEB Code 从 68.76 提升到 78.68，适合本地代码检索和隐私优先的多模态 RAG，但跨设备延迟、召回率和量化损失仍需按自己的语料验证。官方发布
    • Falcon-Emirati-7B 针对阿联酋方言与文化语境做专项适配。 TII 结合真实方言网页、文化语料和受词表约束的合成数据，报告在 1,173 道 Alyah 方言题上达到 84.83%；开放生成的方言忠实度由 Gemini 3.7 Flash 担任评审。它说明“小模型 + 本地方言数据”可胜过更大的通用模型，但 benchmark、训练方和主要评测仍高度同源，不列为今日头条。技术文章
    • ArXiv cs.AI 10 月 6 日新增 554 条；列表页本次只稳定提取到编号，未仅凭编号和摘要缺失条目凑数。

    产品 & 工具¶

    • OpenAI Decisions API 进入公测，专门做高速分类、路由和评分。 /v1/decisions 目前只支持 gpt-6-luna，可对文本或图像返回 predicate 概率、固定 choice 分布或 rubric score；官方称速度约为 Responses API 的 10 倍，输入价 $0.10/百万 token、无输出 token 费用。它很适合 Agent 路由和审核队列，但概率不是校准保证，必须用自有标注集设阈值并保留人工兜底。官方文档
    • Claude 进入 Google Docs、Sheets 和 Slides。 付费 Claude 计划可在 Google Workspace add-on 公测中直接读写当前文件；默认模式逐项审批，另有“接受全部编辑”模式。Sheets 可写公式、透视表和图表并调用 Python 清洗数据；Enterprise 的 CMEK、Compliance API 和 OpenTelemetry 审计仍适用。对自动化而言，真正重要的是编辑审批与 Google 共享权限沿用，不能把“在文档里运行”误当作权限天然安全。官方文章
    • OpenAI 与 Atlassian 扩大合作，GPT-6 系列将进入 Rovo 和 Teamwork Graph；3,000 多名 Atlassian 开发者已在使用 Codex。方向值得留意，但今天更直接可试的是 Decisions API 与 Claude Workspace 集成，因此不单列头条。官方说明

    公司 & 融资¶

    • Mistral 把 ML4 明确定位为欧洲主权 AI 基础设施。 模型用欧洲自有数据中心的 3,800 张 Grace Blackwell GPU 训练，并承诺月底发布权重；“开放权重 + 私有部署 + 网络安全能力”是差异化核心。不过权重、许可证、部署成本和真实吞吐均未落地，不能仅凭预告判断可控性。
    • Anthropic CVP 的分级开放表明前沿厂商正在从“一刀切拒绝”转向“身份验证 + 用途分层 + 审计留存”；这会提升专业防守能力，也把资格审核、数据保留和责任边界变成产品能力的一部分。

    开源 & 社区¶

    • morluto/rea — 今日首次观察进入 GitHub Trending，约 9.5K stars / 1.0K forks，当日约 +2,956 stars；MIT。REA 用一个 MCP/CLI 把 Ghidra、Hopper、IDA、JavaScript/Electron、APK 与固件分析接给 Coding Agent；10 月 6 日发布 4.1.0，新增静态 APK、固件、Windows x64 Ghidra 和 IDA provider。强热度和正式 release 都成立，但它触及反编译器、目标二进制和本机 Agent 配置，且部分 provider 依赖商业工具或实验平台，必须在授权目标和隔离环境中试用。
    • FeSens/openTPU — 新建约两周的 Apache-2.0 开源 FPGA AI 加速器，约 217 stars / 8 forks；Hacker News 约 223 points / 288 comments。仓库把 RTL、ISA、位精确模拟器、编译器、profiler 和 PCIe host 软件放在同一 monorepo，并称已在 Kintex-7 卡上跑通 Qwen3、Qwen3.5、Gemma 4 与 LFM2 系列。证据包含硬件计数器、测试方法和 token 对齐说明，但项目无正式 release、只验证了特定旧 FPGA 卡，性能数字主要由作者自测；值得读设计，不宜当成熟推理平台。
    • pbakaus/impeccable — 今日首次观察进入 Trending，约 77.7K stars / 4.6K forks，当日约 +616 stars；Apache-2.0，10 月 2 日发布 Skill 4.5.0。它为 Coding Agent 提供 1 个设计 skill、24 个命令、60 条确定性 UI 检测规则和浏览器迭代工作流，支持 Claude Code、Codex、Cursor、Gemini 等。成熟采用度较高，但安装器会写多种 harness 的 skill/hook，并可能下载本地 engine binary；引入前应固定 release、核验签名并审查 hooks。
    • 72 小时观察：mattpocock/skills — 首次观察进入 Trending，约 278K stars / 23K forks，MIT，最新 v1.3.1 发布于 10 月 4 日；包含 TDD、调试、规格、review、并行实现等工程 skills。页面未给出可靠当日增量，且仓库规模大、跨 skill 调用和插件自动更新边界需要抽查，先进入 72 小时复查队列。
    • 观察结束：calesthio/OpenMontage — 约 64.7K stars，较昨日约 +658，但已离开本次 Trending，仍无正式 release；72 小时窗口结束，因 700+ skill/知识文件、多 provider 供应链和 AGPL 边界未收敛，标记为低优先级。
    • 观察结束：michael-denyer/pstack-claude — 约 1.5K stars，较昨日约 +115，已离开 Trending；虽继续更新但增速下降且仍是 0.x 多 harness 移植层，标记为低优先级。
    • GitHub Trending 中 tester-army/e2e、earthtojake/text-to-cad、thedotmack/claude-mem、msitarzewski/agency-agents 等已在历史日报或账本出现，连续上榜不重复。Hacker News best 原站继续返回 419，改用 Algolia 前台列表核验；Product Hunt、36kr、量子位分别被反爬、安全检查或 403 阻断，未使用旧缓存冒充今日内容。

    🔧 跟我们相关的¶

    • 优先做一个 Decisions API 的离线路由评测。 用现有任务分类样本测 predicate/choice 的召回率、拒绝率、置信度校准和成本；阈值由误分代价决定，不直接把官方“10 倍速度”当生产结论。
    • 给 EmbeddingGemma 2 做本地代码检索小样。 用一份可公开仓库对比当前 embedding：索引大小、Top-k 命中、中文/代码混合查询、量化后延迟和 RAM；它的 270M 文本模式比完整多模态更适合先跑 MVP。
    • REA 只在授权样本和隔离工作区试跑。 先用静态 JavaScript/APK fixture 验证 evidence 输出，不运行未知二进制、不自动安装 Hopper/Ghidra、不让 MCP 接触私人项目。
    • Mistral Large 4 等真正开放权重再测。 先记录 API 预览的 Coding/Agent 成功率和成本，月底权重、许可证、模型卡到位后再比较私有部署；今天不改生产 provider。
    • Claude Google Workspace 若要接入，应保留默认逐项审批，并核验 connector 与 Google 文件共享权限、审计日志和撤销路径；“Accept all edits”只用于可恢复副本。

    💡 一句话观点¶

    今天的主线不是单纯“模型更大”，而是能力正在被拆成可部署的部件：开放权重负责主权与可控，高速决策模型负责路由，端侧 embedding 负责私密检索，分级验证负责高风险权限；下一阶段的竞争会落在这些部件能否被安全地拼起来。
