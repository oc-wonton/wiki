## 📰 行业动态

### 模型 & 研究

- **Muse Wonder 的差异化叙事是 Active Memory 与 Active Focus。** 前者让模型跨会话保留并主动检索个人上下文，后者强调遇到阻塞时持续尝试、调整计划并在关键动作前确认。Meta 同时展示长周期软件开发和跨应用浏览器任务，模型已可调用 API，但完整安全评估尚未公开；涉及消息、日历和私人文档时，应把数据保留、可删除性、工具权限与审计日志视为采用前置条件。
- **GLM-Legal 把领域模型训练和 Agent harness 迭代绑在一起。** 智谱称模型在数万真实风格法律环境中学习规划、工具调用和交付物生成，再把“漏事实、浅分析、格式偏差”等失败回流到环境、评分规则与 harness。这个工程路径比单纯刷领域选择题更接近真实工作，但官方基准和案例仍缺独立复现；Harvey LAB 19.2% 的严格全通过率应被理解为进步信号，而不是可无人值守的可靠性证明。
- **[RATED：工具检索不只看语义，还要根据运行失败动态降权](https://arxiv.org/abs/2610.13889)。** 论文配套 EcoAgent，含 5,172 个真实工具与超过 21 万 query-tool 对；其冻结双编码器负责语义匹配，轻量 contextual bandit 根据实时执行反馈重排。作者报告在 30% API 故障场景中，把选中故障工具的比例从 86.2% 降到 2.9%，额外延迟低于 1ms。它直接对应 OpenClaw 的 provider/tool 健康路由，但数字来自作者实验，真实多租户环境中的反馈污染、冷启动和错误归因仍待验证。
- ArXiv `cs.AI` 新列表为 10 月 12 日批次，共 161 条；除 RATED 外，本次没有再用单篇作者自测结果凑数。OpenAI、Google AI、Anthropic News 与 Hugging Face 在上次成功运行后的窗口里未发现需要压过上述发布的新条目；Anthropic Engineering 当前置顶的 containment 文章已在 9 月 5 日日报推送，不重复。

## 🔧 跟我们相关的

- **先对 Muse Wonder 做最小路由 Spike，不给私人上下文。** 选 10 个公开、可验收的长任务，比较 Muse Wonder 与当前主模型的完成率、工具错误、追问质量、持续执行时间和成本；在安全报告、数据保留与删除机制明确前，不接消息、日历、个人文档或持久记忆。
- **把 RATED 的思想加入 provider/tool 路由。** 工具选择分成“语义适配分”和“近期健康分”，对超时、权限错误、schema 错误和服务端故障分开统计，避免一次供应商故障把所有工具一并降权，也避免把模型参数错误误判为服务不可用。
- **审计所有 Coding Agent 的后台进程与更新边界。** 对 Codex、Claude Code、OMP 等统一检查：启动后新增哪些进程、是否常驻、如何停止、更新来源、继承哪些 proxy/cwd/env、谁持有凭据。无人值守运行时优先锁版本并保留可验证的退出路径。
- **God’s Eye View 只做隔离、假数据评测。** 如果要测试 MCP 与空间情报交互，先用公开非敏感区域、只读工具和无真实 API key 的环境；核验许可证、数据源条款、日志、origin/Host 限制和模型可见数据范围后，再决定是否进入 OpenClaw skill 候选。
- **GLM-Legal 暂时只当“领域 Agent 共训”案例。** 可以借鉴其把任务环境、评分规则和 harness 一起迭代的方法，但不要把官方演示或 19.2% 全通过率解读为法律交付可自动化；任何真实合同、争议材料和跨境合规建议都必须人工复核。
