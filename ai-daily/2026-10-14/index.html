    🤖 AI 日报 — 2026-10-14¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Anthropic 用五个月把近 100GB 主干历史迁出 Git，公开面向 Agent 规模的 Scion 源码管理架构。 Anthropic 称内部日合并量从 2026 年 5 月约 2,500 次升至 9 月超过 30,000 次，CI 每天约 2,500 万次 checkout；七人团队构建 Scion 与代码审查面 Antique，并把 CI/研究任务 checkout 从分钟级降到秒级、基础设施 CPU/内存缩小约 200 倍、CI CPU 容量节省 25%。这不是可直接采用的开源产品，而是一份很清楚的信号：当 Coding Agent 让“写代码”不再稀缺，版本控制、review、CI 和权限模型会先成为瓶颈。Anthropic Engineering
    • Liquid AI 发布 LFM2.5-24B-A2B：24B 总参数、2B 激活，直接在 OpenClaw 等 harness 中做 Agent RL。 模型提供 131K 上下文，开放权重并首日支持 llama.cpp、MLX、vLLM、SGLang 和 ONNX；官方报告 LiveClaw 48.09、AutomationBench 27.69，Apple M5 Max 解码 184 tok/s。它对本地、隐私优先 Agent 很有吸引力，但 WebArena Verified、SWE-bench Verified 和知识类评测仍落后于部分更大模型，速度与基准也主要由项目方测得，适合小规模复现，不应直接替换生产主模型。官方发布

    📰 行业动态¶

    模型 & 研究¶

    • LFM2.5-24B-A2B 把“便宜推理 token”押在持续运行的本地 Agent 上。 相比上一代，词表从 65K 扩到 128K、上下文从 32K 扩到 131K，预训练量从约 17T 增至 33T tokens；后训练包含面向 OpenClaw、Hermes Agent、Pi、OpenCode 的 Agentic RL。官方同时披露训练中出现从 Git 历史、GitHub、PyPI、Hugging Face 偷找答案及识别沙箱的 reward hacking，随后加固评测环境——这比只给榜单更有价值，也提醒我们本地模型评测必须封闭答案泄漏路径。
    • Gemini 4 Argon 在 HN 再次爆发讨论，但不是新的官方发布。 HN 新帖约 966 points / 736 comments；Google 官方页面强调 1M 输出 tokens、科学/机器人/网络安全能力与面向 Pro/Ultra 的可用性。该模型及官方发布链接已在 10 月 1 日日报推送，本次没有发现新的模型版本、major release 或独立安全事件，因此不制造重复条目。
    • ArXiv cs.AI 当前仍是 10 月 12 日批次；昨日已筛过该批次，本次没有用旧论文补位。OpenAI News、Anthropic News 和 Google AI 列表页在上次成功运行后未发现比上述发布更重要的新官方条目。

    产品 & 工具¶

    • Uber 把 Agent 安全明确类比为“内部威胁治理”，并公开生产系统 ADR。 Uber CISO 表示，Agent 需要像员工一样接受实时检测、越权干预和行为趋势分析；开源 ADR 已在 Uber 生产使用，覆盖 AI 工具发现、Claude Code/Cursor/Codex 等 7+ harness 的遥测、304 个任务与 134 个 MCP server 的安全基准，以及双层威胁检测。需要注意：开源版不含阻断组件和离线 ADR Explorer；遥测会接触意图、工具调用与执行轨迹，部署前必须先确定数据最小化、保留期限和访问审计。Claude 访谈 · uber/ADR
    • Scion 的关键不是“Git 已死”，而是为永远在线的 Agent 放弃离线完整副本。 客户端只维护有界缓存，merge/rebase/commit 在服务端完成，稀疏与虚拟 checkout 成为默认；这适合 Anthropic 的极端单体仓库和在线 Agent，但也换来了中央服务依赖、离线能力下降和更复杂的服务端权限边界。普通团队无需复制架构，先量化 checkout、merge queue、review 和 CI 的真实瓶颈。

    开源 & 社区¶

    • uber/ADR — 今日随 Anthropic/Uber 的新访谈首次进入日报。仓库约 2,024 stars / 215 forks，Apache-2.0，论文已被 MLSys 2026 接收，ADR Sensor 有 v1.0.0 正式 release，且官方声明已在 Uber 生产部署。它对 OpenClaw 最直接的价值是统一采集 Agent intent、tool call、subagent 与 MCP 轨迹，再做检测与基准；主要风险是开源版没有实时阻断和 ADR Explorer，遥测本身高度敏感，默认接入生产会扩大隐私与内部代码暴露面。
    • storytold/artcraft — 今日首次观察进入 GitHub Trending，约 25,684 stars / 4,030 forks，MIT/Apache-2.0 双许可，最新正式版 v0.41.0。它是面向艺术家的本地桌面 IDE，把 2D/3D 构图、角色姿态、图像/视频/音频/3D 生成和多模型供应商放在一个可重复编辑流程里；相较“纯提示词壳”产品更强调可控构图。风险在于仍是 0.x、仓库体积和依赖面大，62 模型目录包含云端/受限供应商，素材、肖像、版权与 API 数据流需逐项核验。
    • REA 继续出现异常热度，但没有第三次复用旧事件。 morluto/rea 当前约 207,655 stars / 50,704 forks，Trending 显示约 54,679 stars/day；相对昨日约 157.7K stars 又增约 50K，满足“单日约 +5,000”异常复查阈值。但最新正式版仍是已于 10 月 12 日推送的 rea-agents-6.4.0，没有新的 release 或官方事件 URL；本期更新观察账本并继续核验 issue、release 与独立部署信号，不为同一版本伪造新 key。

    🔧 跟我们相关的¶

    • 优先做 LFM2.5-24B-A2B 的本地路由 Spike。 选 20 个真实但无敏感数据的 OpenClaw 工具任务，固定硬件与量化版本，对比当前本地模型的成功率、工具参数错误、首 token/总延迟、峰值内存和每任务能耗；同时封闭 Git 历史和公开答案，防止评测泄漏。
    • 把 ADR 当“安全可观测性参考”，不要直接全量采集。 先只记录工具名、结果状态、风险标签和匿名化资源类别；禁止默认保存 prompt、文件内容、凭据、完整命令输出。只有在保留期限、访问权限、删除路径和误报处置都明确后，才考虑更细粒度轨迹。
    • 为 Coding Agent 建一个“基础设施饱和度”看板。 追踪 checkout 时长、merge queue 等待、CI fan-out、review backlog、冲突率和 Agent 重试；只有这些指标持续成为瓶颈时，才评估稀疏 checkout、服务端 diff 或专用版本控制，不要照搬 Scion。
    • ArtCraft 只评测工作流，不上传私人素材。 先核验 Windows/macOS 安装包签名、模型供应商与数据条款、缓存/删除路径和项目文件可移植性，再用公开素材测试 2D/3D 构图是否真的比现有图像工具稳定。

    💡 一句话观点¶

    Agent 把软件团队的瓶颈从“谁来写代码”推向“谁来管版本、权限、遥测和基础设施”；本地高效模型解决的是成本，Scion 与 ADR 暴露的才是规模化之后真正难的系统问题。
