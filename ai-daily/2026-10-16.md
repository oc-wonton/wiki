## 🔥 今日头条

- **Meta 开放 Muse Spark Open 权重：816B 总参数、42B 激活、原生多模态与 100 万 token 上下文。** 模型面向 coding 与长程 Agent 任务，可接收文本、图像、音频和视频并调用工具；BF16 权重约 1.5 TB，NVFP4 可在单个 B200 节点运行，官方还展示了两台 512 GB M5 Ultra Mac Studio 的本地部署。HN 约 598 points / 337 comments，说明社区关注度很高。它是 open-weight 而非宽松意义上的完全开源，使用 Muse Model License 且商业条款有限；关键 benchmark、端侧速度和安全结论主要来自 Meta/Hugging Face，仍需独立复现。[Meta 官方](https://research.meta.ai/blog/muse-spark-open) · [Hugging Face 技术指南](https://huggingface.co/blog/meta-muse-spark-open)
- **OpenClaw 2026.10.4 发布，集中修复 Gateway 稳定性与一条 owner 冒充路径。** 这是 2026.10.3 的稳定性补丁：系统休眠或时钟跳变后 Gateway 不再因 heartbeat 误判重启；shutdown/restart 不再被 transcript worker 或 session lifecycle 卡死；Tlon 群 DM 不再把其他参与者当作 owner；手动 `/compact` 会先让活跃 run 收敛，避免丢掉待处理请求。没有新功能或配置变更，但对无人值守自动化属于高价值维护版本。[OpenClaw 2026.10.4](https://github.com/openclaw/openclaw/releases/tag/v2026.10.4)

## 📰 行业动态

### 模型 & 研究

- **IBM Granite Switch 4.1 把聊天、决策/安全分类和语音识别组合进一个端点。** 8B 与 30B 版本通过 Activated LoRA 复用基础模型 KV cache，并共置 ASR encoder；官方称可在接近基础模型的显存占用下切换 chat、通用 decision、guardian 与 speech-to-text。模型和 adapter 可组合，适合把 Agent 路由、guardrail 与语音入口放在同一部署面，但跨模型胜率、60–100 decisions/s 和 RAG 竞速主要是项目方评测，Adapter SDK 也尚未发布。[Hugging Face / IBM](https://huggingface.co/blog/ibm-granite/granite-switch-4-1)
- **Muse Spark Open 的“桌面运行”门槛仍接近工作站集群。** MoE 每 token 仅激活约 42B 参数，但全部 816B 权重仍需驻留；官方 BF16 方案是 4×8 H200，NVFP4 是单 B200 节点，Apple 路径需要两台顶配 M5 Ultra。它对多模态工具调用和长上下文 Agent 很有研究价值，却不是普通开发机可以直接替换现有模型的方案。

## 🔧 跟我们相关的

- **优先评估 OpenClaw 2026.10.4 升级。** 先核对当前版本与 changelog，再在可回滚环境验证：休眠/时钟跳变后 Gateway ownership、长回复、手动 compact、自动化运行、Feishu/微信会话绑定和安全相关群聊身份判断；这是维护版，不需要为新配置迁移买单。
- **给 XERJ 做一个只读、离线、最小数据集 Spike。** 不执行 README 的一键安装，不用 `--insecure` 暴露到非 loopback；从源码或已校验资产启动带认证实例，只索引一个公开小仓库，比较 grep 与 XERJ 的 token、命中率和总耗时，并核验它不会把私密文件、凭据或无关目录纳入索引。
- **把 Granite Switch 的架构思路用于本地路由评估，而不是立刻部署模型。** 重点验证“共享基础模型 + 专项 decision/guardian adapter + ASR”是否真能降低多模型常驻成本；先看模型卡、许可证、公开 eval 和独立复现，再决定是否做 GPU Spike。
- **Claude Code Review 只作为第二审查者。** 若 Team/Enterprise 已可用，可挑一个低敏仓库对 Quick/Standard/Deep 做盲测；以真实 bug、误报、延迟、数据边界和成本为验收指标，不把自动 review 当 merge gate 的唯一证据。

## 💡 一句话观点

> 今天的共同信号不是“模型更大了”，而是 Agent 栈正在分层：大模型负责长程多模态推理，轻量 decision adapter 负责路由与守卫，本地索引负责压缩上下文，而可靠运行仍靠版本修复、认证和独立验收兜底。
