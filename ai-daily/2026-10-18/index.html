    🤖 AI 日报 — 2026-10-18¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • OpenCode 披露安全事件，部分 Console 用户的模型供应商凭据可能暴露。 OpenCode 官方称，一个正在下线的旧系统遭未授权访问，影响约 1.4% 的 OpenCode Console 用户；其通知邮件要求受影响者撤销并替换保存在 workspace 中的 OpenAI、Anthropic 等第三方 provider keys，并检查异常用量。官方把事件与“大规模蒸馏攻击”联系起来，但截至本期仍未发布完整时间线、攻击路径或取证报告。Hacker News 约 742 points / 126 comments，讨论重点集中在云端 BYOK 的信任边界。若使用过 OpenCode Console/Zen 并保存过 provider key，应立即轮换，而不是等待完整复盘。OpenCode 官方公告
    • DeepSeek 发布 DeepSeek-V4.1-Flash-1017，并开放 Search / Fetch API。 这是 V4.1-Flash 的小版本更新，官方称在 reasoning、coding、Agent 和视觉任务上同时改善，并减少执行时间与输出长度；模型权重与代码采用 MIT，支持 100 万 token 上下文、最高至少 256K 输出，并发布 deepseek-recipe 处理 Messages、Chat Completions、Responses API、工具调用和多模态 prompt 编解码。Search / Fetch 每个 endpoint 定价为每千次 0.75 美元，DeepSeek API 用户通过 DeepSeek Harness、Claude Code、Codex 的服务端工具调用暂时免费至 10 月 31 日 16:00 UTC。benchmark 主要来自官方，仍需独立复现。DeepSeek 官方发布

    📰 行业动态¶

    模型 & 研究¶

    • DeepSeek-V4.1-Flash-1017 的真实增量是“更短、更快的 Agent 执行”，而不只是榜单上涨。 官方报告 Terminal-Bench 4.0 从 31.2 提升到 42.3、DeepSWE v1.1 从 74.2 到 77.0、Automation-Bench 从 54.8 到 60.5；这些均为项目方测试，且不同模型的 harness 与采样条件未必完全一致。值得验证的是同一真实任务下的完成率、工具参数正确率、输出 token 与总成本，而不是跨模型单点排名。
    • ArXiv cs.AI 最新仍为 10 月 16 日批次（首屏显示 286 条）；本期没有仅凭标题硬凑论文。Anthropic News、Anthropic Engineering 与 Claude Blog 均完成检查，未发现相对昨日账本的新官方卡片。

    产品 & 工具¶

    • OpenCode 事件再次暴露“本地开源客户端 + 云端 Console/BYOK”容易被误解为同一安全边界。 本次公开信息指向旧云端系统和保存在 workspace 的 provider keys，不等于已证明纯本地 CLI 本身泄露凭据；但在完整复盘出来前，任何把第三方 key 交给 Console 的用户都应按已暴露处理。官方尚未给出受影响时段、日志保留、密钥加密方式和攻击者访问范围，这些是后续采用判断的关键。
    • llmspeed 提供“买硬件前先感受本地模型速度”的交互式估算。 网站按 GPU/Mac/CPU 和模型浏览，用动画还原预估 token 速度；项目明确区分社区实测与基于相似配置/规格推算的数据。它适合做采购前的第一轮筛选，不适合替代本机 benchmark。llmspeed

    开源 & 社区¶

    • stablyai/orca：多 Coding Agent 的桌面/移动控制面。 今日首次观察进入 GitHub Trending，约 95,419 stars、+830/day，并于 10 月 17 日发布 v1.4.229；支持 Claude Code、Codex、OpenCode、Pi、OMP 等 CLI Agent，用独立 worktree 并行执行、远程 SSH、手机监控和 diff review。成熟发行链和 MIT 许可加分，但约 8,543 open issues、300MB 级桌面包、远程控制/账户切换/浏览器与 computer-use 权限面都要求先做供应链和权限审计。GitHub
    • android/skills：Google Android 团队维护的官方 Agent Skills。 今日首次观察进入 Trending，约 8,428 stars、+355/day，Apache-2.0，最新 v1.0.15；技能遵循开放 Agent Skills 标准，重点覆盖评测显示 LLM 仍薄弱的 Android 工作流，可通过 Android CLI、Claude Code 或 Codex 插件安装。风险在于官方暂不接受公共贡献，release notes 很薄，整包安装前仍需逐个审查 skill 内容和适用版本。GitHub
    • nicorobinreal/llmspeed：本地 LLM 硬件速度预览站。 仓库仅约 77 stars、无正式 release，但 Hacker News 约 248 points / 77 comments，属于高讨论、低采用度的早期新锐项目。MIT、数据来源说明清楚；主要风险是部分数字为推算值，短 prompt、单设备条件也不能代表长上下文、并发或真实 Agent 工作负载。GitHub
    • 72 小时观察候选：akitaonrails/ai-memory。 今日首次观察 Trending，约 9,924 stars、+178/day，并于 10 月 17 日发布 v3.1.1；它以 git-backed Markdown 为事实源，在 Claude Code、Codex、OpenCode、OMP、OpenClaw 等 harness 间共享记忆和 handoff。定位与我们高度相关，但生命周期 hooks、长期记录、跨用户服务和可选后台整理都涉及隐私与权限面，先进入复查队列而非直接建议安装。GitHub
    • 已推送仓库复查： anthropics/claude-plugins-official 从约 40,569 增至 41,763 stars（本日 +1,397），xerj-org/xerj 从约 6,932 增至 7,804（+1,160/day），debpalash/VoiceStudio 从约 71,217 增至 73,390（+2,125/day）。三者均未达到自上次推送 3 倍、单日约 +5,000，也未发现新的 major/breaking release 或改变采用判断的安全事件，因此不重复报道。
    • Hacker News 原站继续返回 419，已通过 Algolia API 核验热榜；Product Hunt 与量子位返回 403，36kr 停在安全检查页，Google AI 列表页未稳定提取新卡片。失败源均未用旧缓存冒充今日更新。

    🔧 跟我们相关的¶

    • 立即核查 OpenCode Console 暴露面。 如果曾在 OpenCode Console/Zen workspace 保存 OpenAI、Anthropic、Google 等 provider key：撤销旧 key、创建新 key、更新依赖、检查 10 月 17 日前后的调用与账单，并缩小额度和权限；不要在聊天或日志里粘贴新 key。
    • 给 OpenClaw 的 provider 凭据建立最小权限基线。 能由本机 SecretRef/受保护存储直接注入的，就不要上传到第三方控制面；把预算上限、异常用量告警、轮换周期和“供应商控制台一键撤销”写进运行手册。
    • 用同一批真实 Agent 任务盲测 DeepSeek 1017。 至少比较旧版与 1017 的成功率、工具调用 JSON、总输出 token、延迟和成本；Search / Fetch 先在低权限测试项目中评估来源质量、日志和 prompt-injection 边界。
    • Orca、Android Skills 与 llmspeed 都先读后装。 Orca 重点审计远程控制、账户和遥测；Android Skills 逐个导入；llmspeed 只用来筛硬件候选，最终采购前跑真实模型、上下文和并发 benchmark。

    💡 一句话观点¶

    今天的共同主题是“控制面才是风险集中地”：模型更强、Agent 更多并不自动带来可靠性，凭据托管、远程执行、技能安装和性能估算都必须有可撤销、可验证、最小权限的边界。
