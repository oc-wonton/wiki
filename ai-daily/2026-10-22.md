## 🔥 今日头条

- **LiteLLM 1.107.0 的 PyPI 包被植入凭据窃取器与远程执行后门，已构成会改变采用判断的重大供应链事件。** SafeDep 复核发现，全部七个跨 Linux、macOS、Windows wheel 会把 `cook.pth`、`cook.py` 和 `sitecustomize.py` 装入 `site-packages`，从而在任意 Python 进程启动时窃取 SSH、云平台、CI/CD、浏览器、AI 开发工具和 LiteLLM proxy 数据库凭据，并每小时尝试下载执行二阶段代码；PyPI 已移除 1.107.0，1.106.2 与两个 1.107.0 RC 被验证为干净。上游公开 GitHub 源码不含恶意文件，SafeDep 对“私有发布流水线从攻击者修改过的源构建”给出中高置信判断，但根因仍需 BerriAI 日志确认。[SafeDep 技术分析](https://safedep.io/litellm-pypi-compromise-credential-stealer-backdoor/) · [GitHub](https://github.com/BerriAI/litellm)
- **Anthropic 推出 Claude Duet 研究预览，把 Claude 做成会主动汇报、持续后台执行并在高风险动作前等待批准的个人 Agent。** Duet 由 Opus 5.5 驱动，继承 Claude 的 memory、skills 与 connectors，在独立云端虚拟机中运行，每隔数小时检查连接账户，可通过 6,000+ connectors 完成邮件、日程、发票、工资、合同、CRM、商店等任务；发送消息、付款、签署和删除前需显式批准。当前仅面向美国 Pro/Max 用户候补开放，后台检查与大任务会消耗共享额度，而且官方明确承认它可能误读线程、误判紧急度或漏掉两次检查之间的新事项。[官方文章](https://claude.com/resources/articles/claude-duet)

## 📰 行业动态

### 模型 & 研究

- **IBM 发布 Granite Speech 5.0 系列，覆盖高精度多语转写、边缘高速转写与多人说话归属。** 新 2B 模型支持英、法、德、西、葡、日转写及多方向英语翻译，可用最多 2,000 个术语做 keyword biasing；470M Turbo CTC 扩展至七种语言，官方称吞吐从约 12,600 RTFx 提升到 19,870 RTFx；更新后的 4.1 2B Plus 报告长音频 WER 下降 24%、时间戳偏移减半。三者均为 Apache‑2.0，并接入 Transformers，2B 版还支持 vLLM、llama.cpp 和 MLX；性能主要来自 IBM 与公开 leaderboard，应在真实噪声、方言和多人重叠语音上独立复测。[Hugging Face](https://huggingface.co/blog/ibm-granite/granite-speech-5)
- **NVIDIA Kumo Relational 试图用一个预训练关系型基础模型直接替代每个数据库预测任务的特征工程与单独训练。** 它保留表、外键和时间结构，以最多 10,000 个历史样本做 in-context prediction；官方在 15 个数据库、41 个任务上报告胜过关系型深度学习和专家构造的 GBDT，并称在 SAP SALT 上较 AutoGluon ensemble 高 8% MRR。代码为 Apache‑2.0、权重使用 OpenMDW 1.1，可从开源 `structured-data-models` 或 NIM 调用；但 benchmark、500B+ 行扩展和生产替代结论主要来自厂商评测，权重许可证也不是 Apache‑2.0。[Hugging Face](https://huggingface.co/blog/nvidia/kumo-relational) · [代码](https://github.com/NVIDIA/structured-data-models)
- **VocabX 提醒小模型优化不应只盯权重，领域 tokenizer 也可能是大成本杠杆。** Dharma AI 在葡萄牙语作文评分器上把 Qwen3‑4B 词表从约 15.2 万缩至约 6.5 万，并用 macro token 压缩固定 JSON 与高频领域短语；作者报告平均输出从 350 降至 101 tokens、测得推理成本下降 77%，同时 benchmark 分数从 0.703 升至 0.810。方法和论文仍在准备/审稿，结果来自单一团队与特定任务，适合作为“可复现实验方向”，不应直接外推到开放域 Agent。[Hugging Face](https://huggingface.co/blog/Dharma-AI/vocabx-vocabulary-specialization)
- ArXiv `cs.AI` 已更新到 10 月 21 日批次，首屏显示 321 篇；本期没有仅凭标题、缺少讨论或复现证据的新论文入选。

### 产品 & 工具

- **Claude Security 从一次性扫描升级为持续跟踪代码变化、修复状态与团队上下文的安全平台。** 新版可连接 GitHub/GitLab，多仓库建立可编辑 threat model，依据变更风险自动复扫，修复落地后自动关闭 findings、复现后重新打开；同时提供 API、webhooks、MCP connector 和角色权限控制。它仍是 Claude Enterprise 公测，扫描效果和“一百万漏洞”属于厂商数据，且代码、威胁模型、访问令牌与 MCP 接口会形成新的高价值权限面。[官方文章](https://claude.com/resources/articles/claude-security-now-scans-continuously-and-tracks-fixes)
- **Claude Duet 把 OpenClaw 式“主动检查 + 后台任务 + 审批门”带进 Claude 消费级产品。** 有价值的不是 6,000 个连接器数量，而是明确区分自动准备与外部副作用：读、草拟和准备可后台完成；发消息、付款、签署和删除必须停在可见审批点。研究预览仍是黑盒云端服务，且共享用量、检查间隔、美国地区与独立 App 都限制了现阶段可用性。[官方产品页](https://claude.com/product/claude-duet)

## 🔧 跟我们相关的

- **立即排查 LiteLLM 1.107.0。** 在主机、容器镜像、虚拟环境、CI cache 与 lockfile 中查版本和 IoC；如果安装过，按主机已执行凭据窃取器与后门处理：先隔离，再轮换云、SSH、CI/CD、GitHub、LLM provider、浏览器和 LiteLLM proxy 凭据，并重建环境。仅降级或删除三个恶意文件不够。
- **把供应链 provenance 纳入 Agent 依赖准入。** PyPI 包必须对照 tag/source、hash、签名/attestation 与可复现构建；高权限 gateway、MCP server 和 Agent runtime 优先固定 digest，并在隔离环境中安装与扫描。
- **借鉴 Claude Duet 的审批边界，不照搬黑盒云端。** OpenClaw 自动化可继续遵循“读取/整理/草拟可自动，外发/付款/签署/删除必须显式批准”，并把每次副作用前的完整 action preview 作为验收项。
- **Granite Speech 5 值得做一个小样本中文外语混合语音 benchmark。** 用真实会议噪声、术语表、多人重叠和长音频对比现有 ASR；只有 WER、说话人归属、延迟和本地资源都达标才考虑接入。

## 💡 一句话观点

> 今天最重要的不是又多了一个主动 Agent，而是两条同时发生的现实：Agent 正在获得更大权限，而它依赖的供应链仍可能在一次普通安装中拿走所有凭据；能力扩张必须和可验证构建、最小权限、审批门、凭据轮换一起交付。
