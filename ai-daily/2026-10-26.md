## 🔥 今日头条

- **一项可复查的小样本实验显示，十年前的专用 CNN 在皮肤癌图像分类上明显优于两个前沿多模态 LLM。** 皮肤科医生 Magnus Lynch 在 200 个病理确诊病灶上测试：微调 Inception v3 首选诊断正确率 62%，GPT-6 Astra 与 Claude Fable 5.1 均约 42%。作者公开病例、prompt、模型回复和评分代码；但样本仅 200、每个 LLM 病例只跑一次，CNN 在预设阈值下会漏掉更多黑色素瘤，不能外推为临床建议。它提醒我们：通用模型的“会看图”不等于领域决策可靠，专用模型与任务阈值仍然重要。[原始实验](https://lynchlab.net/llm-skin-cancer)

### 模型 & 研究

- **专用模型再次证明“任务适配”可能比通用能力更重要。** 上述皮肤癌实验在相同六分类任务上让专用 CNN 取得 125/200，而两个前沿 LLM 分别为 84/200 与 85/200；不过安全处置结果取决于阈值，不能只看 top-1 accuracy。对 Agent 评测的启发是：必须把最终业务后果、阈值和重复运行稳定性纳入验收，而不是只比较一次回答是否像专家。[实验与数据](https://lynchlab.net/llm-skin-cancer)

## 🔧 跟我们相关的

- **把皮肤癌实验的方法论迁移到 Agent 验收。** 同一任务至少重复运行，分别记录 top-1、关键漏判、业务阈值与最终处置后果；不要只用一次“回答像专家”作为可靠性证据。
- **Hallmark 只借鉴规则，不整包安装。** 优先提取“功能保留检查、多宽度截图、fresh-context UI reviewer”三项，逐项静态审计后再落成自己的 UI 验收 skill。
- **ThinkRail 值得做隔离体验评测。** 用无生产凭据的小仓库比较它的 worktree、living specs、MCP 权限与 OpenClaw/现有 ACP 流程；关闭可选遥测并核对安装包签名。
- **Microduck 暂作为 embodied-agent 架构样本。** 重点阅读它的 policy/runtime 分离、签名更新、健康门和回滚设计；没有硬件与安全边界前，不做实体控制实验。
