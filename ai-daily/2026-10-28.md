## 🔥 今日头条

- **Google DeepMind 发布 Genie 4，把世界模型推进到可实时操控、原生音频和 Agent 训练环境。** 它可在运行中用自然语言修改天气、镜头、人物和物体，由 Gemini 3.8 Flash 持续观察、规划和校验多步事件，并开始面向可信测试者、Project Genie 与 Gemini API 早期伙伴预览。当前仍会出现物体恒常性、文字、空间精度和长时一致性漂移，且性能证据主要来自项目方演示；它更像重要的训练/原型平台信号，还不是可用于高风险物理决策的可靠模拟器。[官方发布](https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/)
- **Anthropic 的随机对照研究显示，专业分析师在开放判断题上 86% 跟随 Agent 被随机植入的倾向。** 50 名使用 Claude Code 的因果推断分析师中，77% 至少一次复述 Agent 的论据，只有 15% 标注来源；即使分析师先形成意见，Agent 反对时仍有 60% 改变选择。研究只覆盖单一任务、单一模型，且故意强化了 Agent 倾向，不能直接外推到所有专业工作，但它把“human in the loop 不等于独立判断”变成了可测量风险。[Anthropic 研究](https://www.anthropic.com/research/agents-judgment-calls)

## 📰 行业动态

### 模型 & 研究

- **Liquid AI 发布 LFM3 六模型家族。** 共享约 2B 参数级 backbone，覆盖文本、视觉/视频、音频、omni 和两种校准决策模型；文本模型 4-bit 约 1 GB、256K context，可在单 GPU 微调，并明确适配 Hermes Agent、Pi 和 OpenClaw。LFM3-1.7B 相比 LFM2.5-2.6B 少 35% 参数，项目方报告 WebArena-Verified 38.42 vs 3.02；视觉、音频和 omni 指标同样主要来自厂商自评，`trust_remote_code=True`、模型许可证、量化质量与真实端侧速度仍需单独核验。[Hugging Face / Liquid AI](https://huggingface.co/blog/LiquidAI/lfm3)
- **Ai2 发布 Novelty Judge Benchmark，发现 LLM 判断科研创意“是否新颖”对提示词极其敏感。** 在一组 Human+Generated 对比中，只改几句话就让 GPT-5.4 准确率从 93.5% 降到 40.9%；更强推理与实时检索没有稳定提升结果，成本约高 10 倍。研究开放论文、299 个基于 ICLR 2026 评审构建的人类创意样本、生成样本、数据和代码；AI 生成创意的“较不新颖”标签仍属于弱标签，适合用来检测评审不稳定性，不应被当成绝对真值。[Ai2 / Hugging Face](https://huggingface.co/blog/allenai/novelty-bench)
- **Anthropic 公布 Claude 参与药物研发的六项早期合作。** 案例包括约 35,000 个抗体设计、1,010 个实验变体、监管文档审查时间减少 89%，以及一个 CAR-T 设计在实验中把受体表达提高约 10 倍；合作方提供了技术报告和部分实验结果。多数项目仍处于临床前阶段、缺少独立大规模复现，不能把早期实验命中等同于药物有效或临床成功。[Anthropic](https://www.anthropic.com/research/early-progress-drug-development)
- ArXiv `cs.AI` 更新到 10 月 27 日批次，共 433 篇；本次未发现单篇同时具备强外部讨论、开放代码和直接采用价值，未用摘要列表凑数。

### 产品 & 工具

- **OpenClaw 2026.10.8 发布，重点修复升级恢复、会话续接与安全边界。** 新版让普通 Doctor 失败后 Gateway 可恢复，修复被终止运行的 recovery fence、子 Agent/Claude CLI/Codex 完成回传、长回复和插件生命周期问题，并强化 exec allowlist、Node 浏览器代理、sandbox child、密钥错误信息和恶意嵌套内容防护。它与当前 OpenClaw 部署直接相关，但升级仍应先做快照、检查 release notes 和在可回滚环境验证。[Release](https://github.com/openclaw/openclaw/releases/tag/v2026.10.8)
- **Claude Blog 给出 Claude Code 成本与 ROI 的 `control → track → prove` 框架。** 可用 gateway 按用户/组/组织设置日周月额度、服务端模型 allowlist，结合 OpenTelemetry 按 skill、plugin、agent、MCP server 观察 token、成本与工具活动，再与 Git/工单中的实际交付关联。文章也明确：prompt 日志因可能包含敏感内容而默认不采集，不能用代码行数或“Claude 创建的 PR 数”替代实际合并和业务结果。[Claude Blog](https://claude.com/resources/articles/how-to-manage-costs-and-demonstrate-roi-for-claude-code-on-google-cloud)
- **OpenAI 与 Oracle 扩大合作，把 Oracle 应用和数据接入 ChatGPT。** 规划中的 Oracle AI Workspace 将财务、采购和计划数据置于组织权限与审批之下；同时发布 AI Security Mesh、SMB Bundle 和 App Composer，并允许美国 Oracle 客户通过 Marketplace 采购 OpenAI API、Codex 和 ChatGPT Work。当前多项能力仍是“designed to / goal”，应等待实际可用性、权限映射和审计证据，不把合作声明当成交付完成。[OpenAI](https://openai.com/index/oracle-apps-in-chatgpt/)

## 🔧 跟我们相关的

- **先做 OpenClaw 2026.10.8 的可回滚升级评估。** 当前部署最相关的是 Gateway/Doctor 恢复、子 Agent completion、Claude CLI/Codex 续接和 exec/sandbox 安全修复；先核对当前版本与 breaking notes，快照后再灰度，不在日报任务里直接升级。
- **把“人类审批”升级为“独立判断记录”。** 对高影响 Agent 任务，先让人写下目标、关键选择和不可接受结果，再让 Agent 给建议；审查时要求同时呈现最强反方论据，避免审批者只是在 Agent 的叙事里按确认键。
- **可用真实 OpenClaw 任务小测 LFM3，但先隔离。** 选择本地文本路由、工具选择和结构化输出任务，记录成功率、端侧内存、速度、误调用和量化损失；不要在生产主机直接启用远程代码和高权限工具。
- **借 Claude 的成本框架补齐内部观测。** 先看“每个完成任务的成本、重复运行稳定性、人工返工、最终是否交付”，而不是 token 总量、代码行数或 PR 创建数；prompt/工具结果日志默认按敏感数据处理。
- **`ai-design-skills` 只抽规则，不整包安装。** 优先吸收 section-by-section 修改、proof 靠近 claim、完整交互状态和可访问性验收；对字体、禁用连字符、强制视觉 token 等主观规则保留项目级覆盖权。
