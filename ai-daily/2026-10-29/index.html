    🤖 AI 日报 — 2026-10-29¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Google 发布 Gemini 4 Carbon，把前沿模型重点压到长时 Agent 与网络安全。 Google 称 Carbon 可连续运行数日处理大型代码库和底层系统问题，在 Artificial Analysis Intelligence Index v5.0 得 59 分；无 guardrail 评测下，SEC-bench Pro 漏洞发现 88.2%、ExploitGym 利用验证 54.8%、CWE-bench 修复 71.0%，并称间接提示注入评测攻击成功率为 0%。但多数关键数字仍来自 Google/合作方评测，当前只向部分网络防御者和 Fairwind 可信伙伴逐步开放，尚未普遍提供给开发者；“更强攻击能力”和“更强防护能力”是同一枚硬币，必须等待独立复现与实际访问边界。Google 官方
    • Surge AI 的 DAYJOB: Tax 显示，当前最佳 Agent 在专业税务端到端任务上通过率只有 10.8%。 50 个环境覆盖 8 类税务工作、1,789 个文件，并以 95% rubric 阈值衡量计算、证据、遗漏问题和最终交付；Claude Sonnet 5.5 以 10.8% 居首，Fable 5.1 为 9.6%，Opus 5.5 为 9.2%。它比单题问答更接近“客户没问对问题、材料互相冲突”的真实工作，但榜单来自评测机构自建封闭任务，仍需外部复现；结论很清楚：高风险专业 Agent 目前适合辅助，不适合无审计地独立签字。DAYJOB: Tax

    📰 行业动态¶

    模型 & 研究¶

    • NVIDIA 发布 Nemotron 3.5 Transcribe 与 Granary v2。 30B-A4B 开放权重模型每 token 约激活 4B 参数，可转录 40 种语言、英译/译英 31 种、为 13 种语言标注最多 8 位说话人，并处理最长一小时录音；Granary v2 开放覆盖 48 种语言、463,062 小时的 manifest 与可复用清洗管线。官方与第三方榜单显示其在开放权重 ASR、长音频和说话人归属上领先，医疗场景 held-out speakers 微调把 WER 从 22.44% 降到 12.17%；当前量化版和本地 NeMo-Speech.cpp 仍未到位，模型面向录音而非实时流，语言支持也因任务而异。NVIDIA / Hugging Face
    • ArXiv cs.AI 更新到 10 月 28 日批次，共 254 篇；本次未发现一篇同时具备强外部讨论、开放实现和直接采用价值的论文，因此不以摘要列表凑数。

    产品 & 工具¶

    • Cursor 发布 GA 的 Agent SDK。 团队可把 prompt、TypeScript 工具、连接器和 eval 放进同一代码项目，响应 GitHub/GitLab/Bitbucket 等事件，支持子 Agent、并行任务、事件回放和本地 eval；既能一条命令部署到 Cursor，也可作为单个 Node 进程自托管。它把 Agent 从“聊天配置”推进到可审查、可版本化、可回放的软件资产，但 Cursor 托管面的权限、密钥、网络出口和运行时隔离仍需单独审计，不能因为自带 eval 就默认生产安全。Cursor
    • Claude Enterprise 上线 Smart reports、应用内调查和团队共享预算。 Smart reports 会抽样分析团队 transcript，按 workstream 汇总交付物、成本、失败工具和可沉淀 skill/rule；调查收集“失去 Claude 会卡住什么”等价值反馈；共享预算让团队共用月度额度，同时保留个人上限。方法上很适合借鉴，但 transcript 抽样本身是新的隐私与劳动监督边界，Anthropic 也明确不应将报告用于个人绩效或雇佣决策。Claude Blog
    • OpenAI 与 ServiceNow 扩大企业工作流合作。 新集成计划让 ChatGPT 在 ServiceNow 权限与业务规则下查询相似事件、评估变更风险和更新记录；ServiceNow MCP plugin 已上架，但增强功能预计 2026 年底，安全能力、Codex AI Workflow Factory 与多项产品能力要到 2027 年早期或更晚。当前真正可用的增量有限，大部分仍是路线图，采用前应区分“已上线 MCP”与“未来安全/开发 Agent”。OpenAI
    • OpenClaw 2026.10.10-beta.4 预发布修复了定时运行、子 Agent 与凭据边界。 新版让 scheduled runs 等待工具结果再汇总，修复 Codex native 子 Agent 完成后父会话阻塞、Claude CLI 上下文重置，并阻止环境引用的 hooks.token 泄露到 host exec/CLI child 环境，同时回补嵌入式运行时安全修复。它与当前日报和 Agent 编排直接相关，但这是 prerelease，不应在生产上直接追 beta；先在可回滚环境验证，等待稳定版再升级主实例。Release

    公司 & 融资¶

    • Anthropic 扩大与美国 GSA 的合作。 Claude Enterprise、Claude for Government 和 Claude API 获 40% 政府折扣，并首次覆盖州、地方、部落和领地政府；Anthropic 称约 500 个美国政府组织已使用 Claude，政府版周活自 2 月增长约 8 倍、联邦民事机构用量一年约增 20 倍。案例与节省 10 亿美元估算主要由供应商提供，不能替代采购、权限和实际成效审计；更值得关注的是，Claude for Government 已达到 FedRAMP High，并把高权限 Agent 更深带入公共部门。Anthropic
    • OpenAI 的《The future of the firm》是署名观点文章，讨论 AI 位于员工之下、同级或管理层之间的三种组织结构；它不是 OpenAI 官方预测或产品发布，本期不把观点稿包装成硬新闻。

    开源 & 社区¶

    • nightly-labs/openbot 达到 72 小时观察队列的推送门槛。 项目约 3,256 stars / 316 forks，今日 Trending 约 +1,054；相较昨日约 2,446 stars 又增约 810，并在数小时内连续发布 v0.53.0–v0.53.2，加入后台 Agent memory review 等能力。它提供本地优先的持久 AI 队友工作区，覆盖 Codex、Claude、Grok、任务队列、浏览器控制和 Agent 协作；但仍是 development preview，默认 full-access 权限面大，GitHub 许可证元数据为 NOASSERTION、README 使用 PolyForm Noncommercial。强热度值得关注，不等于适合生产安装。GitHub
    • HKUDS/DeepTutor 发布 v1.7.0，形成可复报的新事件。 相比 4 月首次推送时约 1,310 stars，当前约 47,989 stars，已远超 3 倍增长门槛；新版本把核心 chat/CLI/SDK 与完整 Web app 模块化，新增 Dito block notebook、Word 导入导出、带字幕/可选朗读的视频课程，以及可恢复索引和更稳的 prompt caching。它已是 Apache-2.0、带正式 release 的成熟候选，但升级涉及 deeptutor / deeptutor-cli 包迁移、Node 22、动态模块和生成代码，必须先备份 runtime home 并隔离执行。Release
    • expo/skills 首次进入本账本 Trending。 Expo 官方仓库约 3,581 stars / 228 forks、MIT，提供 20+ 个面向 Expo Router、React Native、SDK 升级、EAS 构建/发布/观测和远程模拟器的 Agent skills，并区分免费 SDK 能力、付费 EAS 与实验 API；Claude Code/Codex 可走官方 plugin marketplace，其他 coding agent 可用 skills CLI。它的官方来源、清晰边界和跨 Agent 兼容性比单纯热度更有价值，但安装 skill 与 MCP 会扩大工具面，EAS 部分还涉及付费云服务和发布权限，应逐个审查而非全量导入。GitHub
    • 已推送 Trending 仓库复查： JetBrains/thinkrail 约 5,059 stars、今日 +1,068；elayadesign/ai-design-skills 约 11,127、今日 +2,139；makecindy/cindy 约 8,105、今日 +728。它们都未达到单日约 +5,000、自上次推送 3 倍或新的 major/breaking release，因此不重复报道。obra/superpowers 与 ruvnet/RuView 也属历史已推送项目，连续上榜本身不算新增。
    • 72 小时观察候选：macro-inc/macro。 项目约 5,423 stars / 519 forks、今日 +117，AGPL-3.0；把邮件、聊天、文档、任务、CRM、通话和 Agent 记忆放进统一双向链接图，并开放 MCP 与自托管代码。产品面和工程量很大，但会集中极高敏感度的团队数据，且自托管包含 42 个服务、167 个 Rust crates 与云基础设施；当前热度增长不强，先观察安全模型、部署成本和独立采用证据。GitHub
    • Hacker News 已检查：Gemini 4 Carbon 约 791 points / 651 comments，是窗口内最强 AI 新增讨论；DAYJOB: Tax 与 Cursor Agent SDK 也进入热门。Product Hunt 返回 403，36kr 停在安全检测页，量子位返回 403；失败源未用旧缓存冒充今日更新。

    🔧 跟我们相关的¶

    • 优先等 OpenClaw 稳定版，不追 beta。 但把 beta.4 的 scheduled-run tool settlement、Codex child completion、Claude CLI 上下文与 hooks.token 隔离列入回归清单，稳定版到来时做针对性验收。
    • 借 DAYJOB 的方法改造 Agent 验收。 测试不能只问“回答对了吗”，还要放入冲突材料、遗漏附件和用户没意识到的关键期限，验收 Agent 是否主动发现问题并把证据带进最终交付。
    • 评估 Cursor Agent SDK 时优先看 replay + eval。 选择一个低权限、可回滚的 PR 分类或文档一致性任务，比较事件回放、失败可解释性和权限最小化；不要一开始就接生产事件与写权限。
    • expo/skills 值得逐个阅读，不建议一键全装。 若近期有 Expo 项目，先审 expo-upgrade、expo-router 和 eas-update-insights；涉及 EAS 发布、模拟器和 MCP 的 skill 必须另做权限审核。
    • OpenBot 继续只做隔离评测。 热度与 release 速度已过观察门槛，但非商业许可、默认 full-access、浏览器/文件/凭据能力面都决定了它不适合直接接入主工作区。

    💡 一句话观点¶

    今天最强的信号不是模型 benchmark 又涨了，而是 Agent 正同时进入网络安全、税务、企业流程和政府系统；能力越接近“连续自主工作”，越要把权限、证据、回放和独立验收当作产品本体，而不是上线后的补丁。
