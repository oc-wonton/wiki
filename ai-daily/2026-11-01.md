## 🔥 今日头条

- **研究人员披露一个已修复的 ChatGPT 公共分享链接接管漏洞。** Parameter Security 发现，攻击者可把普通 ChatGPT share、HTML Preview 与图表加载的 MathLive 监听器组合起来，让恶意 JavaScript 以 `chatgpt.com` 身份运行；受害者最坏只需打开分享链接，攻击代码就能调用已认证 API、枚举并读取未分享的私有对话，再把数据传出。OpenAI 将报告提升为 P1，并于 10 月 26 日确认两个 Web 前端均已修复。事件说明“各自看似隔离”的功能经过 `postMessage`、HTML 注入和未 sandbox 的 `srcdoc` 串联后，仍可能跨越产品安全边界。[技术披露](https://www.parameter.ai/labs/we-found-a-gap-at-openai)
- **Claude 为法律团队上线可复用、可分享的 Artifacts 模板库。** 首批覆盖引文核对、跨法域调查、事项看板、合同偏离检查、监管时间线和批量合同表格化，并为每项输出保留来源链接；同时开放 60 多个法律连接器和九个公益司法模板。它把 Claude 从“回答法律问题”推进到可协作的工作流组件，但高风险法律判断仍需律师复核，连接器权限、客户资料隔离与 ethical wall 不能只靠模板默认值。[Claude Blog](https://claude.com/resources/articles/introducing-artifacts-for-legal-work)

## 🔧 跟我们相关的

- **把分享链接视为不可信输入。** 对 Agent/聊天产品的公开 share、HTML preview、artifact 和富媒体组件做组合式测试；所有 `postMessage` 接收器必须同时验证 `event.origin` 与 `event.source`，不让跨窗口配置携带原始 HTML，并保证由不可信内容影响的新文档继续处于 sandbox。
- **先小规模对比 Lightpanda，再谈替换。** 选一组 OpenClaw 真实浏览任务，比较成功率、登录态隔离、CDP/Playwright 兼容、内存和延迟；确认 AGPL 与部署方式可接受后再扩大使用。
- **Orkas 只做隔离评测。** 若要借鉴其 Commander + specialist agents 设计，先用无生产凭据、无外部发布权限的测试工作区观察任务拆分、审批、恢复与审计日志，不直接安装后连接现有账号。
- **法律 Artifacts 值得借鉴的是“来源 + 状态 + 人工审批”的交付结构。** 可把同样模式用于 OpenClaw 的研究、审查和合规任务，但最终判断必须由具备责任的人签字。
