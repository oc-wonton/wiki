## 🔥 今日头条

- **“权重空间编程”首次展示前沿 LLM 直接读写神经网络权重的强能力，但结论仍需独立复现。** Rikiya Taori 等人的实验称，GPT-6 Astra 不依赖梯度训练，直接修改 Qwen3.5-0.8B 的 0.016% 权重，就把同采样设置下的 MATH-500 从 7.9% 提升至 48.1%，IFEval 约提升 3 倍；它还可从原始权重识别小网络任务、修复控制策略并从零写出游戏网络。文章在 Hacker News 约 1,845 points / 579 comments。若结果可复现，模型优化将不再只有“写训练代码”一条路径；但目前实验、评测和叙事主要来自作者，涉及单一前沿模型，权重编辑的泛化、可重复性和安全边界尚未得到独立验证。[原文](https://rikiyat.github.io/blog/weight-space-programming/)
- **Claude Platform 推出 Message Threads 公测，直接优化超长 Agent 会话的首 token 延迟。** 客户端首次发送完整上下文，后续只提交新增消息与前一响应 ID；Anthropic 称 50 万至 100 万 token 请求的 TTFT 中位数约下降 35%。线程只在内存中加密保存、闲置 5 分钟过期；模型每轮仍读取完整会话，因此 token 用量和费用不变。这是传输与排队优化，不是上下文压缩。[Claude Blog](https://claude.com/resources/articles/message-threads)

## 📰 行业动态

### 模型 & 研究

- **Weight-Space Programming 把“让 LLM 优化模型”从训练脚本推进到了权重本身。** 作者展示了读取任务语义、识别中间层 copying heads、单次修复失败控制策略、从零写 MinAtar/Go 网络，以及直接修改 Qwen 权重等八组实验。最值得关注的是方法路线，而不是单个 benchmark 数字：通用模型可能把解释、诊断和局部权重修复统一为一个推理任务。最大风险也很清楚——结果主要由作者团队在 GPT-6 Astra 上完成，尚缺跨模型、跨随机种子和第三方复现；直接编辑权重还可能引入难以发现的能力漂移与后门。[实验文章](https://rikiyat.github.io/blog/weight-space-programming/)
- ArXiv `cs.AI` 更新至 11 月 2 日批次，共 186 条；本次没有发现同时具备强外部讨论、开放实现和直接采用价值、且优于上述权重空间实验的新论文，不以摘要列表凑数。

### 产品 & 工具

- **Claude Message Threads 已在原生 Claude Platform、AWS、Microsoft Foundry 和 Anthropic-managed Google Cloud 公测。** 它适合高频调用的 Coding Agent、computer use 和图像/文档重工作流；Claude Code 多数用户默认启用。采用前要注意线程只有 5 分钟寿命，断档后客户端仍需能完整重发上下文，且该功能不降低 token 账单。[官方说明](https://claude.com/resources/articles/message-threads)

## 🔧 跟我们相关的

- **优先做 Message Threads 的协议层评估。** 如果 OpenClaw 的 Claude provider 支持该参数，可用 50 万 token 长会话比较 TTFT、线程过期恢复、重试幂等和断线后的完整上下文重发；不要把它误记为 token 成本优化。
- **给 `agent-desktop` 设计一套权限最小化验收。** 只在无个人账号的隔离桌面开放单个应用，记录 snapshot 中是否泄露其他窗口、剪贴板和通知；动作必须有前后状态断言，并明确 headed/headless 的差异。
- **本地 MoE 推理优先比较 `colibri` 与 `FreeToken` 的真实 Agent 负载。** 使用同一模型、量化、上下文和硬件，测 TTFT、长会话增量轮次、decode、峰值内存、磁盘读放大和输出一致性；作者 benchmark 只能当线索。
- **暂不把权重直接编辑用于生产模型。** 先等待公开代码与第三方复现；若实验，只允许小模型、可回滚权重、固定评测集、行为差异扫描和独立安全检查。
