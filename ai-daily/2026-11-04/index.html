    🤖 AI 日报 — 2026-11-04¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Postman 被指在未明确同意下，把插件、启动 hook、远程 MCP 和 CLI 写进 Codex/Claude Code 的用户级环境。 一位 macOS 用户提交的可核验证据包括 Postman 12.33.4 日志中的 auto-existing-upgrade、被修改的 ~/.codex/config.toml、宽泛要求 API 任务优先加载 Postman skill 的启动指令，以及安装器源码中尝试把自家 hook 写入 trusted state 的逻辑；Hacker News 约 999 points / 331 comments。报告明确没有声称已发生数据外传，目前也只是单台机器的事件记录、尚无 Postman 官方根因说明，但它已经足以把“插件安装必须逐项、显式同意”提升为 Agent host 的安全基线。GitHub Issue
    • 昨日“权重空间编程”的强叙事遭到高质量拆解，结论应下调为“模型能辅助做权重分析与修改”，而不是“仅看原始权重就能重写大模型”。 Matthew Honnibal 指出，真正只读原始权重、无工具运行的实验限于 17K–172K 参数的小网络；Qwen 数学提升实验使用了 Python、运行模型并查看最多 50 批练习题，且同法在 Gemma 上失败。Simon Willison 独立验证了较弱但仍有趣的部分：本地 Qwen 3.8 27B 在长时间推理后能从小型策略网络权重识别 Pac-Man、Pong、Breakout，但 Freeway 失败。前者在 HN 约 886 points / 190 comments，构成对昨日头条的重要增量纠偏。Honnibal · Simon Willison

    📰 行业动态¶

    模型 & 研究¶

    • CWE-bench v2 开放 100 个真实仓库安全修复任务，覆盖 91 类 CWE。 每个任务给 Agent 一个真实开源仓库和简短修复指令，用确定性 verifier 检查漏洞是否修复、原功能是否保留，并专门测试记忆上游补丁的解法是否会失败；另有 held-out 集维持污染外评测。项目方报告 11 个模型中 Gemini 4 Argon 为 67.8% pass@1 / 81.0% pass@4，Claude Opus 5.5 为 67.3% / 78.0%，仍有 19% 任务没有任何一次被领先模型解出。公开集、grader 和 Harbor harness 可复现，但榜单仍由 benchmark 维护方设计和运行，不能单独代表真实生产安全能力。Hugging Face
    • 权重空间实验的增量价值主要落在“可审计的模型辅助分析”，不是超人式直读权重。 Honnibal 的实验拆分显示：小网络 raw-float 识别、写小型游戏网络、对大模型做代码辅助分析和局部修改，是三类不同能力，不应合并成单一突破；Qwen 本地复现实验说明前一类能力并非 GPT-6 Astra 独有，但耗时 46–65 分钟、4 个游戏失败 1 个，远未证明通用性。
    • ArXiv cs.AI 更新至 11 月 3 日批次，共 521 条；本次没有发现同时具备强外部讨论、开放实现和直接采用价值、且优于上述可复查结果的新论文，不以摘要列表凑数。

    产品 & 工具¶

    • Postman 事件暴露的是 Agent 生态的控制面风险，而非普通插件体验问题。 报告中的安装逻辑跨越了应用边界：修改两个 coding agent 的全局配置、注册远程 MCP、加入会话启动指令，并尝试写入 hook 信任记录。即便最终确认没有数据外传，默认安装、默认路由和自我批准也违反最小权限与用户可归因原则。采用结论应等待 Postman 官方回应、干净环境复现和完整卸载说明，但现阶段应先审计本机插件目录与启动 hook。

    开源 & 社区¶

    • 成熟候选 max-sixty/worktrunk 首次进入本账本 Trending：约 10,491 stars / 377 forks，今日 +438。 它把 Git worktree 做成面向并行 Coding Agent 的工作流层，提供创建/切换/清理、每 worktree 启动 Claude/Codex、hook、共享 copy-on-write build cache、CI/PR 摘要和签名发行制品；最新正式版 v0.81.0。它不是新仓库，但“首次观察且从未推送”满足 Trending 增量规则，对 OpenClaw 多 Agent 隔离直接有用。风险是 shell integration、生命周期 hook、自动 merge/commit 和 LLM 摘要都会扩大本地执行面；README 链接 MIT，但 GitHub API 许可证元数据为 NOASSERTION，采用前应核对具体文件和 hook。GitHub · v0.81.0
    • p-e-w/heretic 首次观察约 38,794 stars / 4,383 forks，并在窗口前沿发布 breaking v2.0.0。 它用可插拔 scorer、modifier 和 Optuna 做免训练模型行为修改，支持降低谄媚或“slop”，默认配置则是压低拒答；v2 新增 arbitrary-rank ablation、通用插件、headless 模式和可复现 manifest，但 1.x 配置不兼容。项目的研究和工程价值真实存在，AGPL-3.0、社区已有大量衍生模型；同时它能主动移除安全拒答，模型行为与安全边界可能出现隐蔽漂移，只适合隔离研究、固定评测和明确授权，不应直接接生产 Agent。GitHub · v2.0.0
    • 昨日推送的 vercel-labs/agent-desktop 已发布 v1.1.0，属于会改变桌面自动化可靠性的能力增量。 新版让 macOS ref 通过元素自身 accessibility address 重新识别，Linux/Windows ref 使用 capture rule 解析，并补齐 macOS Dock、菜单栏状态项和系统面板访问，另修复 Windows 坐标双缩放、退出崩溃和换行问题。当前约 12,762 stars / 881 forks，相对昨日约 +3,063，Trending 显示今日 +3,791；仍未触发约 +5,000/day 或 3 倍热度阈值，本次复报依据是新 release 的跨平台稳定性能力，而非持续上榜。v1.1.0

    🔧 跟我们相关的¶

    • 立即审计 Agent host 的“外来控制面”。 检查 Codex/Claude Code/OpenClaw 的用户级 marketplace、plugin、MCP、session-start hook 和 trusted-hash 记录；任何跨应用安装必须拆成可见、可拒绝、可回滚的逐项同意，插件不能批准自己的 hook。
    • 把 CWE-bench v2 纳入安全 Agent 验收候选。 先选 5–10 个与当前代码栈相关的任务，在固定容器、禁用生产凭据和限制出站网络条件下验证 pass@k、误修复、原功能保持和成本，再决定是否扩大。
    • 用 worktrunk 只做隔离层小试，不启用自动 merge。 先验证 worktree 路径、依赖缓存污染、hook 执行、端口分配和清理回滚；Agent 提交与合并仍保留人工检查。
    • 修正昨日对权重空间编程的内部判断。 将其标记为“值得复现的模型辅助 ML 工程实验”，而不是“模型已能通用理解和直接编程大模型权重”；任何采用结论都需要跨模型、跨随机种子、无工具/有工具分层和安全行为回归。

    💡 一句话观点¶

    Agent 生态今天给了同一个答案：能力不是最稀缺的，边界才是——实验要拆清工具和证据，插件要拆清同意和权限，自动化要拆清隔离和回滚。
