## 📰 行业动态

### 模型 & 研究

- **Hightouch 用“廉价决策模型 + 低置信度升级到 Opus”做到接近前沿模型的准确率。** 在 1,000 个合成身份合并审计样本上，Jev 单独准确率 95.7%、约 $0.05/千条；将 30%–90% 置信区间交给 Opus 后达到 98.8%、约 $0.88/千条，而 Opus 单独为 99.0%、约 $3.86/千条。更难样本中，混合 Jev 为 95.3%、$2.94，Opus 为 95.1%、$5.39；GPT-6 Luna 虽单独更准，但过度自信导致升级策略较差。结论不是某个数字可普遍复用，而是 Agent 路由应评测**置信度校准**，再按不确定性动态花钱；结果来自单一合成领域与项目方实验，外推前必须重做本地 benchmark。[Hightouch](https://hightouch.com/blog/llm-judges-identity-resolution)
- **Ai2 开放 ToyBlocks，用可控模拟世界拆分机器人 Agent 的规划、感知与执行失败。** 框架自动生成任务、skills 和 demonstrations，支持 Isaac Lab、TAMP、VLA/world-model 评测及 MCP 工具；项目方在搜索拼词任务中报告 Agent 成功或正确判定不可行的比例为 63%，并发现让 Agent 通过实验重写 skill description 可把成功率从默认描述的 24% 提高到 63%，高于人工描述的 36%。这些仍是团队自评、窄域结果，sim-to-real 和跨模型泛化待独立复现。[Hugging Face](https://huggingface.co/blog/allenai/toyblocks) · [GitHub](https://github.com/allenai/ToyBlocks)
- Hugging Face 还为 Open ASR Leaderboard 增加埃及和尼日利亚英语的私有会话测试集，以减少 benchmaxxing；方法有价值，但本次数据量仅约 1.34 与 1.55 小时，暂不列头条。[Hugging Face](https://huggingface.co/blog/open-asr-leaderboard-liva)

## 🔧 跟我们相关的

- **把 Agent sandbox 改成纵深防御清单。** 即使底层是 Firecracker，也要强制非 root VMM、jailer/namespace/seccomp、只读根文件系统、最小网络、无宿主凭据、独立审计日志和可销毁工作区；microVM 只是一层，不是安全结论。
- **在模型路由中记录校准曲线。** 对廉价决策模型按置信区间统计真实错误率，只把不确定样本升级到强模型；不要把模型给出的 0–1 分数直接当概率。
- **把 ToyBlocks 的“Agent 自己实验并修订 skill description”迁移到 OpenClaw 小范围试验。** 先选无外部副作用的工具，固定终态验收与调用预算，对比默认描述、人工描述和 Agent 学得描述，避免把窄域自评直接写进生产 skill。

## 💡 一句话观点

> 今天三条线其实指向同一件事：Agent 的能力、成本和安全都不能靠单一模型或单一隔离层兜底，真正可用的系统要会分层路由、可控实验，并假设每一层都可能失败。
