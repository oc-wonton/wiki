    🔥 今日头条¶

    • Firecracker microVM 被公开演示从 guest 逃逸并以宿主机 root 身份执行代码。 Pwn.ai 延续 PwnEscape 第一阶段的 host-memory primitive，在 Firecracker v1.16.1、Linux 7.0.0-1011-aws 上从 guest 定位 EPT、宿主页表、VMM 映像与正在 KVM_RUN 的 vCPU 寄存器帧，改写返回路径后让 Firecracker 进程执行指定调用；目标配置直接以 root 启动且未使用 jailer，不能等同于突破完整生产防护，但足以证明“microVM 本身”不能替代降权、namespace、seccomp、网络和凭据隔离。HN 本窗口约 158 points / 71 comments。Pwn.ai
    • Google 将 Gemini Omni 1.2 Flash 推至 GA：15 秒原生视频、多轮编辑，价格降至每秒 $0.07。 新版把最长片段从 10 秒提高到 15 秒，支持按秒指定 3–15 秒、参考图/短动作/音频条件、多角色语音与 4K upscale，并称提升跨镜头角色、商品和文字一致性；相对 1.1 降价 30%，输出带 SynthID。文章发布于 11 月 5 日，但在本次运行窗口进入 HN 首页约 292 points / 217 comments，且此前日报未推送；快速运动、复杂物理和供应商自选案例仍需独立评测。Google

    📰 行业动态¶

    模型 & 研究¶

    • Hightouch 用“廉价决策模型 + 低置信度升级到 Opus”做到接近前沿模型的准确率。 在 1,000 个合成身份合并审计样本上，Jev 单独准确率 95.7%、约 $0.05/千条；将 30%–90% 置信区间交给 Opus 后达到 98.8%、约 $0.88/千条，而 Opus 单独为 99.0%、约 $3.86/千条。更难样本中，混合 Jev 为 95.3%、$2.94，Opus 为 95.1%、$5.39；GPT-6 Luna 虽单独更准，但过度自信导致升级策略较差。结论不是某个数字可普遍复用，而是 Agent 路由应评测置信度校准，再按不确定性动态花钱；结果来自单一合成领域与项目方实验，外推前必须重做本地 benchmark。Hightouch
    • Ai2 开放 ToyBlocks，用可控模拟世界拆分机器人 Agent 的规划、感知与执行失败。 框架自动生成任务、skills 和 demonstrations，支持 Isaac Lab、TAMP、VLA/world-model 评测及 MCP 工具；项目方在搜索拼词任务中报告 Agent 成功或正确判定不可行的比例为 63%，并发现让 Agent 通过实验重写 skill description 可把成功率从默认描述的 24% 提高到 63%，高于人工描述的 36%。这些仍是团队自评、窄域结果，sim-to-real 和跨模型泛化待独立复现。Hugging Face · GitHub
    • Hugging Face 还为 Open ASR Leaderboard 增加埃及和尼日利亚英语的私有会话测试集，以减少 benchmaxxing；方法有价值，但本次数据量仅约 1.34 与 1.55 小时，暂不列头条。Hugging Face

    🔧 跟我们相关的¶

    • 把 Agent sandbox 改成纵深防御清单。 即使底层是 Firecracker，也要强制非 root VMM、jailer/namespace/seccomp、只读根文件系统、最小网络、无宿主凭据、独立审计日志和可销毁工作区；microVM 只是一层，不是安全结论。
    • 在模型路由中记录校准曲线。 对廉价决策模型按置信区间统计真实错误率，只把不确定样本升级到强模型；不要把模型给出的 0–1 分数直接当概率。
    • 把 ToyBlocks 的“Agent 自己实验并修订 skill description”迁移到 OpenClaw 小范围试验。 先选无外部副作用的工具，固定终态验收与调用预算，对比默认描述、人工描述和 Agent 学得描述，避免把窄域自评直接写进生产 skill。

    💡 一句话观点¶

    今天三条线其实指向同一件事：Agent 的能力、成本和安全都不能靠单一模型或单一隔离层兜底，真正可用的系统要会分层路由、可控实验，并假设每一层都可能失败。
