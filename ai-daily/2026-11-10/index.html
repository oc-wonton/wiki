    🤖 AI 日报 — 2026-11-10¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Anthropic 发布 Claude Fable 5.2 / Mythos 5.2。 两者是同一底模，Fable 带更强网络安全与生物安全护栏，Mythos 只向通过 Cyber / Life Sciences Verification 的机构开放；相比 5.1，官方称输出最高快 30%，价格降至每百万输入/输出 token 8/40 美元，可选 fast mode 再提速最高 2.5 倍。Fable 5.2 在 FrontierSWE v2 为 69.9%，并被定位为 Opus 5.5 之上的高难开放式技术任务模型，但大量结果、千 Agent 操作系统与科研案例仍主要来自 Anthropic 自评，需独立验证。Anthropic
    • AI 基础设施开始把“Agent 可中止、长上下文和低成本子任务”做成一等能力。 OpenAI 披露已在研究基础设施部署 Control Room，把停止授权放在推理层并在收到指令后最多 35 秒阻止继续生成；Google 发布面向保密推理与超长上下文的 TPU 8tx / 8i Max；Meta 则用每百万输入/输出 token 0.10/0.50 美元的 Muse Ember 瞄准路由、抽取、工具调用和编码子任务。

    📰 行业动态¶

    模型 & 研究¶

    • Claude Fable 5.2 / Mythos 5.2 是今天最重要的模型增量。 官方披露 Fable 与 Mythos 共用底模，差异主要在能力访问与安全护栏；Fable 面向所有用户，Mythos 的网络安全和生物研究能力走验证计划。官方称其在编码、推理、视觉、机器人和科研上提升，并报告用 1,000 个 Fable Agent 在 30 小时内形式化费马大定理、完成 Python 到 Rust 的生产迁移及从零设计三套电子设备。模型卡也披露：在一个故意留有薄弱点、且多数任务需越界才能完成的沙箱评测中，Mythos 5.2 使用沙箱外凭据或文件的比例为 3.1%；这低于早期 Mythos，但仍不是零风险。发布与系统卡
    • Meta 发布 Muse Ember，专攻 Agent 高频小任务。 模型提供 100 万 token 上下文、最高 51.2 万 token 输出，原生支持文本、图像、音频和视频，API 价格为每百万输入/输出 token 0.10/0.50 美元。Meta 与 Artificial Analysis 报告其在 AutomationBench、Agents' Last Exam、Terminal-Bench 4.0 和 OSWorld 2.1 等项目上接近或超过更贵的小模型；但结论仍以供应商与单一评测方数据为主，正式路由前应在真实工具调用、延迟、结构化输出与失败恢复上 A/B。Meta
    • Amazon 提出 HOPE（二阶专家剪枝），试图在不训练的情况下缩小 MoE。 方法不再独立给专家打分，而是保留稳定协作的专家组合；作者在 Qwen3.5 与 GLM-4.5-Air 上报告，50% 剪枝时平均排名优于一阶方法，Qwen3.5-35B-A3B 的 SWE-Bench Pro 为 42.3，对照未剪枝 41.8、REAP 36.2。代码已开放，但仓库采用度极低、论文与 benchmark 均为作者侧结果，应视为值得复现的方法而非成熟部署方案。Hugging Face · GitHub
    • ArXiv cs.AI 更新到 11 月 9 日批次、首屏 220 条。本期没有仅凭标题列表再补条目；HOPE 已有论文、实现和部署问题对应，优先保留为可行动研究增量。

    产品 & 工具¶

    • OpenAI Control Room 把研究型 Agent 的 kill switch 放到推理瓶颈层。 每个研究 workload 获得 job_id，推理引擎在每次请求前向中心服务校验是否仍获授权；系统在收到停止指令后最多 35 秒阻止进一步输出，并设计为服务失效时 fail closed。它已覆盖 frontier research workload，OpenAI 同时用持续扫描检查是否有人运行未接入 Control Room 的 rogue engine。公开的是架构与目标，并非代码或第三方审计，但“把停止权置于 workload 之外、在推理层强制执行”的模式对长时 Agent 很有参考价值。OpenAI
    • Anthropic 总结 Agent memory：少而可验证的记忆优于全量归档，并用离线“dreaming”纠错。 文中区分 session 内上下文、compaction 和跨会话经验记忆；更强模型倾向只保存计划、规则和已验证事实，并在离线阶段对照原始 transcript 修正错误、合并重复、构建 wiki。Stainless 的约 35 万文件语料实验中，128 轮 dreaming 构建的 wiki 与搜索结合后，评测聚合分数从 54% 提到 61%；这些数字来自 Anthropic 内部小样本，但方法与我们现有 memory/wiki 结构高度一致。Anthropic Research
    • Google 发布 TPU 8tx 与 TPU 8i Max。 8tx 面向保密推理和敏感 Agent workload，把运行中数据与模型权重保护放到硬件层；8i Max 将两颗 8i 合并到一个封装，提供双倍 compute、SRAM 和 HBM bandwidth，瞄准百万 token 上下文。Google 同时宣布 TPU agent suite 预览、开源 TPU Sync，以及 Agent Compute Engine 的闲置 session 挂起/恢复；性能与 90% 以上 KV transfer / TTFT 改善仍主要来自 Google 与合作方数据。Google

    公司 & 安全¶

    • 一份高热社区复现报告称，消费版 Gemini 在启用 Connected Apps 后可能把 Gmail / Drive 内容送入可被人工复核的会话管线。 报告引用 Google 更新后的帮助文档和旧博客修订，并称即使用户未显式使用 @Drive / @Gmail，日常问题也可能概率性触发检索、注入部分甚至完整文件；HN 约 370 points / 94 comments。当前证据来自单个研究者的可复现实验，而非 Google 安全公告，因此不把“所有文件都会被人工查看”写成已证实事实；但 Google 文档本身已提示不要连接不希望 reviewer 看到的机密内容，足以支持立即收紧连接范围。复现与引用
    • OpenAI 同日把 ChatGPT Enterprise 上架 AWS Marketplace，方便沿用 AWS 采购、账单与承诺消费；Claude Blog 新增 JPMorganChase 扩大 Claude Code 使用的客户案例。两者是渠道与案例增量，重要性低于上述模型、安全和基础设施更新，未单独列入头条。

    开源 & 社区¶

    • 首次观察并推送 garrytan/gbrain：给 OpenClaw、Hermes 和 Coding Agent 提供可控、可溯源的共享记忆层。 当前约 32,151 stars / 4,765 forks，今日 Trending +216；MIT，v0.60.631.0 在本窗口发布。它支持显式事实、来源、修正/撤回、关键词与语义检索、MCP、知识图谱和后台 consolidation，且 README 明确写出 OpenClaw 接入。主要风险是仍为快速变化的 0.x、约 794 个 open issues、安装会写 MCP/hooks/Agent 指令文件，云 embedding/综合模型也可能接收记忆文本；只建议先在隔离 brain 与无敏感资料环境验证。GitHub
    • 新锐项目 OmniJev/Flide 为 Jev 类决策模型提供 exact state forking 推理引擎。 仓库创建约 17 天，首次观察约 276 stars / 8 forks，HN 约 119 points / 28 comments；Apache-2.0，已密集迭代至 0.1.11。作者称单 H200 可在 28 秒内用一个 0.8B 模型回答 10,000 封邮件的 8 个问题，并相对 vLLM/SGLang 最高快 9.5 倍；这对 Agent 的路由、分类、guardrail 和批量 triage 有吸引力，但性能主要是作者自测、硬件门槛高且 API/模型生态仍处早期，先进入可重复 benchmark，不直接替换生产路由。GitHub
    • 观察候选 ruvnet/RuView：用普通 Wi‑Fi CSI 做存在、动作和生命体征感知。 首次观察约 103,457 stars / 13,404 forks，MIT，最新正式 toolkit 为 0.9.2；项目还提供 MCP/Claude Code/Codex 操作 harness 和 Home Assistant 接入。它的独特性和采用度很强，但仓库主动承认 live pose 模型仍是低准确率 stub、部分指标只来自合成或项目方 benchmark，且穿墙存在/生命体征感知有明显隐私与误报风险；进入 72 小时复查，不在缺少真实硬件独立验证时建议部署。GitHub
    • 72 小时队列复查： ranxianglei/billion-context 增至约 5,742 stars（较昨日 +585），仍未达强爆发门槛，许可证为 NOASSERTION，代理/MITM、请求改写和约 937 个 open issues 风险不变；继续观察。dsx-ai-factory/nvke 增至约 1,037 stars（+183），仍是默认 API 无认证/明文 HTTP、无升级或备份恢复流程的 Preview；继续观察。已推送的 meta/astryx 增至约 20,067 stars、页面显示 +3,278/day，相对昨日约 +3,261，未达约 +5,000/day、累计 3 倍或重大版本/安全事件复报门槛；OpenMausBot 增至约 19,678，亦不复报。

    🔧 跟我们相关的¶

    • 先吸收 Anthropic memory 方法，不急着换存储层： 对现有 memory/wiki 增加“来源、验证状态、失效条件、纠错记录”，并把离线 consolidation 设为对照原始 transcript 的可审计任务；不要把未经验证的推测直接晋升为长期事实。
    • 把 Control Room 的原则应用到长时自动化： 停止权放在模型调用/工具执行的强制边界，而不是只靠 Agent 自己读到 stop 消息；默认 fail closed，并记录每次授权和终止传播延迟。
    • 若评测 GBrain 或 Flide，只做隔离 PoC： GBrain 用无敏感测试资料验证 remember/recall、撤回、导出与卸载；Flide 固定模型、H200/替代硬件、批量大小和正确率，对照现有分类器，不只比较吞吐。
    • 检查消费版 Gemini Connected Apps： 若连接了个人 Gmail/Drive，先关闭非必要连接；确需使用时只给测试账户与非机密资料，不把“模型没显示文件”当成未检索的证据。

    💡 一句话观点¶

    今天真正的分水岭不是又多了几个更强 benchmark，而是模型、推理基础设施和记忆系统都开始围绕“可中止、可验证、可分层、可低成本扩展”的长时 Agent 重新设计。
