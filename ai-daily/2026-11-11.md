## 🔥 今日头条

- **Google 全面开放 Gemini 4 Carbon，并用 AlphaProof Code 在四周内形式化验证 Signal 核心密码协议实现。** Carbon 以与 Gemini 4 Argon 相同的每百万输入/输出 token 2/10 美元进入 API、企业与 Ultra 渠道，主攻长时 Agent、网络安全和科研；Google 称其在 CursorBench 4.0、WANDR 和 AutomationBench 排名第一，并预览多 Agent `/swarm`。更硬的工程证据是 AlphaProof Code：人类审核规格，Carbon 驱动的 Agent 生成逾 600 万行 Lean，机器检查绝大部分证明，只把约 1% 代码交回人工复核，还能识别重新植入的两个历史漏洞。模型指标和“四周对比多年”仍主要来自 Google，但形式化产物已开放，值得独立审查。[Gemini 4 Carbon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/) · [AlphaProof Code](https://deepmind.google/blog/introducing-alphaproof-code/)
- **Decision Model 从研究概念进入标准接口与大规模生产案例。** Hugging Face 为 Transformers 增加 `DecisionPipeline`、`AutoModelForDecision` 和统一的 choice / score / noul 接口；Amazon 则披露用 Strands Decider E4B 替代内部工单分类的 Sonnet 4.6，在双跑与人工处理分歧后，平均调用耗时从 4,215 ms 降至 897 ms、估算每百万工单成本从约 22,200 美元降至约 500 美元。它只适合固定选项、高吞吐、无需生成解释的窄任务，而且 JSON key 顺序曾让概率漂移最高 0.19，说明“便宜路由器”也必须做输入规范化与线上 shadow eval。[Hugging Face](https://huggingface.co/blog/decision) · [Amazon/Strands](https://strandsagents.com/blog/amazon-saves-millions-replacing-sonnet-with-strands-decider/)

## 📰 行业动态

### 模型 & 研究

- **Gemini 4 Carbon 正式开放。** Google 将其定位为比 Argon 更深度、更耗 token 的前沿模型，覆盖复杂编码、网络安全、科研和密集文档推理；API 定价与 Argon 同为每百万输入/输出 token 2/10 美元。官方报告 Carbon 在安全红队里阻断 99% 自适应攻击轨迹、Gray Swan 自动网络攻击成功率为 2.17%，并在 375 项 agentic honesty 评测中通过 92%；这些仍需第三方复现，尤其是长时 `/swarm` 的成本、失败传播和权限边界。[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/)
- **AlphaProof Code 把 Agent 生成证明推进到真实生产密码代码。** 框架先由人类与模型共同把 Signal 安全目标写成规格，再由多 Agent 生成并审计 Lean 证明；Google 称它验证了设备暂时失陷前后的消息保护等关键属性，并把两个历史漏洞重新植入隔离版本后均证明为不安全。机器检查能消除“模型自称证明成功”的问题，但规格是否完整仍依赖专家判断；公开形式化产物比单纯 benchmark 更值得复核。[Google DeepMind](https://deepmind.google/blog/introducing-alphaproof-code/)
- **Hugging Face 把 Decision Model 纳入 Transformers。** 新接口直接返回预定义选项的概率，而不是让通用 LLM 生成 JSON；支持 choice、序数 score 和二元 noul，并提供统一 serving endpoint。它适合路由、分类、guardrail 和批量 triage，但概率不天然等于校准置信度，且不同模型、选项顺序和输入序列化可能显著改变输出。[Hugging Face](https://huggingface.co/blog/decision)
- ArXiv `cs.AI` 更新到 11 月 10 日批次、首屏 480 条。本期没有仅凭标题列表补论文；优先保留已有公开实现、生产数据或机器可验证产物的 Carbon / AlphaProof / Decision Model 增量。

### 产品 & 工具

- **Claude 推出 Whiteboards、Sheets 与 Data，并让 MCP Apps 以完整交互应用嵌入 Claude。** Whiteboards 和 Sheets 进入 beta，Claude Dashboards 更名 Claude Data 并 GA；团队可在同一上下文里协作编辑白板、公式、多标签表格和认证查询。Interactive Connectors 现可把 Adobe、Atlassian、Box、Notion 等完整工具开在对话旁，并允许 Claude 在用户审批下直接修改。MCP Apps 能力是 public preview；组织上线前应逐工具限制读写、确认凭据隔离和审计日志，而不是把“沿用现有权限”误当成最小权限。[产品总览](https://claude.com/resources/articles/more-ways-to-work-with-claude-sheets-whiteboards-and-interactive-connectors) · [MCP Apps](https://claude.com/resources/articles/interactive-connectors-full-tool)
- **OpenAI 推出 ChatGPT Business Hub 与 Business Agents beta。** 企业可以认领并维护商品、价格和库存信息，查看聚合的提及/点击主题；美国符合条件的电商和在线服务商可上线独立、明确标注的 Business Agent，并把它作为 ChatGPT Ads 落地页。OpenAI 表示不向商家共享用户原始对话，但“赞助 Agent + 聚合洞察 + 商品目录”让 ChatGPT 更明显地走向商业发现平台，后续需要观察自然回答与付费入口的排序边界。[OpenAI](https://openai.com/index/introducing-businesses-chatgpt/)

### 公司 & 安全

- **Notion 披露 Fireworks AI 安全事件影响少于 1% 的工作区。** Notion 已于 11 月 3 日断开 Fireworks、删除其系统内数据、停止相关流量和训练，并向已识别受影响客户提供聊天 transcript 与敏感信息标注 CSV；官方建议把受影响数据视为已暴露，若曾在 Notion AI 中粘贴密码、API key 或其他凭据立即轮换。事件覆盖开放权重模型推理和 LEAP 训练实验，说明 SaaS 的 AI 子处理商链路与模型本身同样需要数据清单、退出开关和可导出的暴露证据。[Notion](https://www.notion.com/help/security-incident-involving-a-third-party-ai-vendor)
- **VulnCheck 对 Anthropic Project Glasswing 的公开结果提出数据化质疑。** 其追踪到 442 个归因 Anthropic 的 CVE；Anthropic 账本 37,966 个 finding 中 7,349 个公开、217 个标记修复。curl 已公开的 34 份 Anthropic 报告里，19 份被判定不是漏洞、6 份为低危、9 份待评估。文章来自安全厂商且带批评立场，不等同独立审计，但它提出了可核验的维护者负担与重复/撤回口径问题：漏洞发现系统的核心指标不应只是 finding 数，还要看确认率、修复率、严重度一致性和每个有效漏洞的人工 triage 成本。[VulnCheck](https://www.vulncheck.com/blog/anthropic-glasswing-november-update)

## 🔧 跟我们相关的

- **把 Decision Model 加入路由 PoC，但只处理闭集任务。** 选一个现有的分类/优先级判断，固定序列化顺序与 label 文案，做 `旧模型 / 双跑 / 新模型` 三态开关；同时记录准确率、拒绝/低置信分流、p95 延迟和每百万请求成本，不能只看吞吐。
- **评测 Modern Web Guidance v1.0。** 不先全局安装；在隔离前端仓库运行只读 search / legacy-scan，抽查 10 条建议的兼容性、无障碍和代码体积变化，再决定是否加入 coding agent 默认技能。
- **如果接 Home Assistant，先设计权限而不是先连 MCP。** 建立专用本地管理员、默认 read-only、关闭公网 webhook 和文件/YAML beta；把灯光等低风险域与门锁、摄像头、备份、更新、重启分层审批。
- **盘点 AI 子处理商。** Notion/Fireworks 事件值得把“哪些 prompt、附件、记忆、日志会送往哪个模型/推理商”写成可导出清单，并准备一键断开、删除证明与凭据轮换手册。

## 💡 一句话观点

> 今天最值得记住的不是“又一个最强模型”，而是三条工程主线同时成熟：用形式化证明验收高风险代码、用窄决策模型替代昂贵生成模型、用可撤销权限约束能直接改动真实系统的 Agent。
