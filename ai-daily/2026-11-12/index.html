    🤖 AI 日报 — 2026-11-12¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Google 发布 Gemini Decisions API，把“生成答案”拆成更便宜的闭集决策控制面。 新模型 gemini-decision-1 可在一次请求中对同一份文本、图片、音频、视频或 PDF 回答最多 1,000 个 yes/no、choice 或 rubric score 问题，返回候选概率与置信度；官方给出的端到端延迟为 150–250 ms，价格为每百万输入 token 0.10 美元、无输出 token 费用。Google 已将它用于 Gemini Notebook 模型路由、Search MCP 工具安全层等场景。速度、价格和 benchmark 均为 Google 自评，概率也不应直接等同于校准后的业务置信度，但它与昨天 Hugging Face / Amazon 的 Decision Model 进展共同说明：Agent 的路由、策略检查和批量 triage 正从通用生成模型迁往专用决策模型。Google
    • AWS 发布完全由自主 Agent 编写的 AWS Emulator，并公开代码、评测与失败清单。 AWS 称数千个 Agent 基于 438 个 API 模型、真实 AWS 参考行为和数万条 fidelity tests，组成“写测试—找差异—修问题”三类团队；人类没有编写或逐行审查代码，而是设计规格、测试、权限边界和 merge gate。项目覆盖 200+ 服务，已发布 v1.0.322，HN 约 646 points / 211 comments。它是罕见的可审计大规模 Agent 软件工程样本，但官方明确不能用于生产或安全测试，源码构建约需 100 GB 磁盘，遥测默认开启，服务行为仍有公开缺口。AWS · 工程复盘 · GitHub

    📰 行业动态¶

    模型 & 研究¶

    • Tether AI Research 开放 0.8B 参数的端侧 Agent 模型 BotPsy。 模型基于 Qwen3.5-0.8B，提供 safetensors、Q8/Q4 GGUF，主打函数调用与低到中等难度的本地个人助理任务。项目方报告它在 BFCL v4、ACEBench、τ-bench、ToolSandbox 等六项 Agent benchmark 平均得分 45.0，高于其 0.8B base 的 24.7 和 Qwen3.5-2B-Think 的 38.8；但开放搜索 BrowseComp-Plus 只有 4.5，银行多轮任务低于 5，提示注入下不安全响应率仍达 31%。全部核心结果来自作者评测，适合作为本地路由/工具调用候选，不适合高风险自主执行。Hugging Face
    • Hugging Face 给多向量检索加入 pooling-aware training。 在其可复现 Sentence Transformers 实验里，将文档 token vectors 压缩 4 倍时，普通训练模型保留未压缩 NanoBEIR nDCG@10 的 94.6%，加入压缩目标后提升到 97.8%；同时提供 HierarchicalTokenPooling、训练 loss wrapper 和 CUDA kernel 路径。样本只覆盖 12 万条 MS MARCO triplets、NanoBEIR@13 且没有超参搜索，不能直接外推到生产知识库，但对高密度 Agent memory / RAG 的存储成本优化很实用。Hugging Face
    • ArXiv cs.AI 更新到 11 月 11 日批次、首屏 248 条。本期没有仅凭标题列表补论文；优先保留已公开权重、代码、可复现实验或生产接口的 BotPsy、token pooling 与 Decisions API。

    产品 & 工具¶

    • Atuin 18.24 推出 Threads，统一搜索、同步、恢复和跨 harness 分叉 Agent 会话。 它支持 Claude Code、Codex、Pi、OMP 和 OpenCode，可在另一台机器或不同 Agent 中恢复会话，并通过 MCP 搜索历史；同步为端到端加密，可自托管或完全本地，捕获默认 opt-in。价值在于把“未进 Git/issue 的意图、命令和失败尝试”变成可检索工作记录；风险是会话通常包含源码、终端输出和业务上下文，上线团队共享前必须先验证加密密钥恢复、保留期、删除和敏感信息过滤。Atuin
    • United Airlines 禁止未经授权的第三方个人 AI Agent 代订、改签或值机。 United 以账户凭据、支付、里程误用以及联邦行李确认规则为由，准备在自有平台、旅行社和聚合商渠道限制 Agent；Southwest 则选择让 ChatGPT 展示库存。报道来自 CBS，尚未看到 United 的独立政策页，但这已是清晰的采用信号：网页“能被 Agent 操作”不等于业务“授权 Agent 代表用户完成交易”，高风险外部动作需要可验证身份、明确委托和逐步确认。CBS News
    • OpenAI 11 月 11 日更新主要是退伍军人 ChatGPT Plus 公益项目里程碑。 该项目称已有 2 万多名退伍或转业军人领取一年免费 Plus；社会价值明确，但没有模型、API 或产品能力增量，因此不列为头条。OpenAI

    公司 & 安全¶

    • HA-MCP v9.2.0 扩大文件能力，同时补上安全边界。 相对昨天推送的 v9.1.2，新版增加 stored text file 精确 search/replace，并把所有 ha_mcp_tools 服务注册为 admin-only、对 Home Assistant Core 标记为 secret 的 flow 字段做 redaction，还把更多单元测试切到真实 Core。它不是 major release，但“可写文件 + 管理员工具 + secret 脱敏”会改变采用判断；若评测仍应保持独立本地账户、默认 read-only，并把文件编辑列为显式审批动作。v9.2.0
    • Product Hunt 返回 403；36kr 停在安全检测页，量子位返回 403；Anthropic News / Engineering 正文抽取不足，已用 sitemap 交叉核验，窗口内没有超越 11 月 10 日已推送模型事件的新文章；Claude Blog 最新产品文章已在昨天日报覆盖。单源失败未阻塞日报，也未用旧缓存冒充当天更新。

    开源 & 社区¶

    • 新锐项目 aws/aws-emulator 正式开放。 当前约 1,823 stars / 33 forks，CC0（vendor 为 Apache-2.0），v1.0.322 于 11 月 11 日发布；HN 约 646 points / 211 comments。它把真实 AWS 行为转成 Agent 可反复执行的本地验证环境，适合开发和 CI；主要风险是仿真 fidelity 不完整、不能验证安全或生产行为、完整源码构建成本高，以及默认匿名遥测。GitHub
    • 首次观察项目 shadcn/improve：把最强模型用于审计与写规格，把实现交给便宜模型。 当前约 10,882 stars / 443 forks，MIT；它只写 plans/，计划包含精确文件、当前代码、验证命令、STOP 条件和基准 commit，并可在隔离 worktree 调度执行者后复验。设计与我们“经理/验收者不直接写代码”的工作流高度一致；但仓库没有正式 release、最近源码提交停在 9 月，质量证据主要是作者示例，且九类并行审计会显著消耗高价模型 token。GitHub
    • 早期项目 FrigadeHQ/yogurt：本地、无会议机器人加入的开源 AI 会议笔记。 仓库创建不足 48 小时，当前约 403 stars / 11 forks，MIT，已发布 v0.3.6；HN 约 163 points / 73 comments，提供 macOS、Windows、Linux 包和本地构建说明。高热讨论与密集 release 达到新锐席位门槛，但它仍是 0.3.x，麦克风、系统音频、转录模型、更新与预编译包都触及高敏感数据和供应链，使用前需核验录音是否出站及包签名。GitHub
    • 72 小时与已推送项目复查： ruvnet/RuView 增至约 104,062 stars（较昨日 +156），仍无新的独立真实硬件复现，继续观察至窗口结束；dsx-ai-factory/nvke 增至约 1,175 stars（+57），默认 API 无认证/明文 HTTP、升级和备份边界未改善，72 小时窗口结束并降为低优先级。已推送的 meta/astryx 增至约 24,998 stars、Trending 显示 +2,776/day，并发布 v0.7.14，但相对昨天不足 +5,000/day、累计 3 倍或重大能力/安全事件，不复报。

    🔧 跟我们相关的¶

    • 立刻做一个 Decision Model 路由小试验。 选“是否需要深度推理 / 是否可调用某工具”两个闭集问题，对 Gemini Decision 1 与现有大模型双跑；记录准确率、ECE/分桶校准、拒绝分流、p95 延迟和成本，不让未经校准的 confidence 直接触发外部动作。
    • 借鉴 AWS Emulator 的三层门禁，而不是照搬“无人审代码”。 把任务拆为“生成可执行验收—发现差异—单问题修复”，并要求确定性测试、权限边界和独立复验全部通过后才允许合并；人类负责规格和停止条件。
    • 评测 shadcn/improve 的计划质量。 在一个小仓库只跑 quick/read-only，抽查 3 个 finding 的证据、误报、验证命令和范围控制；先看它能否生成更好的 issue/plan，不直接启用自动 execute。
    • Atuin Threads 只在脱敏样本上试。 它明确支持 OMP，适合解决跨机器与跨 harness 会话丢失；先确认捕获目录、端到端加密、自托管、删除和 secret 过滤，再考虑团队共享。

    💡 一句话观点¶

    今天最强的信号不是 Agent 写出了多少代码，而是“决策模型做控制、规格与测试定义正确性、会话历史形成可检索资产”正在拼成一套更便宜也更可审计的 Agent 工程栈。
