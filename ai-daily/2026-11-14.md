## 🔥 今日头条

- **[Gemini 4 Hydrogen 全面开放](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-hydrogen/)** — Google 把面向高频编码与 Agent 执行的 Gemini 4 型号开放到 AI Studio、API、Gemini App、Search 与企业产品；1M context 统一定价为输入 $1.50/M、输出 $7.50/M。官方称其在 Terminal-Bench 4.1 达 57%，相较 3.8 Flash 的 18.2% 明显提升，并由 Antigravity Orchestrator 在 Carbon 与 Hydrogen 间自动路由；这些数字仍以厂商评测为主。

## 📰 行业动态

### 模型 & 研究

- **[llama.cpp 与 ggml 发布 v1.0.0](https://huggingface.co/blog/ggml-org/llama-cpp-v1)** — 这个本地 AI 基础设施项目首次明确采用语义化版本：公共 C API/ABI 的不兼容变更以后必须提升 major 版本。v1.0 同时移除旧 API，加入 FP8 KV cache、MoE expert cache、更多模型/视觉/TTS 架构，并强化 `llama-server` 的 SSRF、CORS、DNS rebinding 与 MCP 取消边界。对依赖 llama.cpp 的本地 Agent 产品，这是比单纯“多支持几个模型”更重要的稳定性里程碑。
- **[XYBench 暴露模型“回答错问题”的系统性缺口](https://huggingface.co/blog/allenai/xybench)** — Ai2、CMU、NVIDIA、JHU 发布 8,115 道 XY 问题基准。五个受测模型在 Stack Overflow 子集上，只有 35%–41% 的回答把重点放在用户真实目标，而不是用户先入为主的错误方案；模型在选择题中能识别更好的答案，却常在自由生成时做不到。数据、代码和论文已开放，但部分样本由模型从 WikiHow 合成，自动 judge 也仍需结合人工复核。
- **[Thinking Machines Lab 公布端到端 4-bit 训练方案](https://thinkingmachines.ai/blog/end-to-end-4-bit-training/)** — Inkling 2 Small 的 MoE 前向使用 NVFP4、反向使用 MXFP8 与随机舍入，项目方报告相较全 MXFP8 预训练墙钟时间快 8%、RL 快 20%。这是训练侧而非仅推理侧的低精度进展，但收益依赖 GB300，且结果主要来自团队自测。

### 产品 & 工具

- **[Claude Meetings 开始 beta](https://claude.com/resources/articles/claude-meetings)** — Claude 可作为可见参与者加入 Google Meet，实时回答、调用已授权工具、生成文档/白板，并保存转录、摘要和屏幕描述。Team 与 Enterprise 逐步开放；默认在外部来宾加入时离场，但管理员可放宽。当前不支持 ZDR、HIPAA-ready 或 CMEK 组织，录制与长期授权仍需明确治理。
- **[Claude Managed Agents 提供全栈自托管 private beta](https://claude.com/resources/articles/self-hosted-claude-managed-agents)** — 企业可把 harness、sandbox、凭据、session history、数据库和 worker 全部运行在自有云或本地，模型请求可走 Anthropic、Bedrock、Google Agent Platform、Microsoft Foundry 或自有 gateway。设计上把 agent loop 与 sandbox 分离，并通过外部代理注入凭据、host allowlist 与 OpenTelemetry 留痕；当前仍需联系 Anthropic 申请。
- **[Anthropic 发布 always-on agent 架构指南](https://claude.com/resources/articles/building-always-on-agents)** — 官方把长期主动 Agent 拆成五个原语：event inbox、timers、memory、permissions、outbox。尤其强调单用户 inbox 只允许一个 active worker、凭据由环境外代理注入、危险工具调用可 deferred 等待批准，以及“先安静、再逐步赢得用户注意力”。这套模型与 OpenClaw 的 scheduler、memory、secret proxy 和 delivery 设计高度同构，值得作为架构复核清单。

### 公司 & 融资

- **[Anthropic 启动 IPO 路演](https://ipo.anthropic.com/us/)** — 官方页面披露计划在 Nasdaq 以 `ANT` 交易，预计 11 月 18 日定价、11 月 19 日挂牌（仍受监管批准影响）。其 Q3’26 页面列出 $17B 收入、同比超 12 倍、调整后营业利润率 15%，但同时有 $23.3B 净亏损，其中 $21.9B 为可转债、衍生负债与 SAFE 公允价值变化造成的非现金费用。

### 开源 & 社区

- **[openai/codex-security](https://github.com/openai/codex-security)** — OpenAI 的安全审计 CLI/TypeScript SDK 首次进入本账本 Trending 观察：13,136 stars、1,024 forks、约 751 stars/day，Apache-2.0。它支持代码/差异扫描、finding 验证、补丁与修复复核、SARIF/JSON/CSV、CI 和多仓库批处理；最新 0.10.0 增加中断扫描恢复与批量成本预算。风险是仍为 0.x、深度扫描依赖模型判断与付费调用，不能替代确定性 SAST 和人工安全评审。
- **[block/buzz](https://github.com/block/buzz)** — Block 的自托管人类-Agent 协作空间首次进入本账本 Trending 观察：37,299 stars、4,941 forks，Apache-2.0，最新 desktop v0.5.30。它把聊天、workflow、Git 事件、审批和 Agent 动作写入同一个签名事件日志，并提供 ACP/MCP/CLI 接入；但约 3,837 个 open issues、快速 0.x 迭代与庞大 relay/桌面/移动栈说明它仍不适合未经隔离直接承载生产凭据。
- **[ggml-org/llama.cpp v1.0.0](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)** — 134,879 stars、25,576 forks，MIT。相对历史项目状态，本次是明确的 major 事件而非连续热门：公共 API 稳定承诺、安全加固和新缓存/模型能力会直接影响大量本地推理下游；升级前应先跑兼容测试，因为旧公共 API 已被删除。
