## 🔥 今日头条

- **[OpenAI 披露 GPT‑6 Astra 辅助提出标准模型的候选格点定义](https://openai.com/index/step-toward-defining-the-standard-model/)** — 物理学家 Nathaniel Craig 把自己的细化格点思路与 Astra 结合，给出在有限格距和场强约束下处理手征费米子测度相位的构造，目标是补上标准模型非微扰定义长期缺失的一环。文章称 Astra 建议了细化格点方案并主导详细证明，但作者同时明确：这仍是候选结果，反射正性、连续极限与实际数值模拟尚未解决，需要领域专家审查，不能把“AI 参与证明”直接等同于定理已获确认。
- **[NVIDIA SkillEvaluator 把 Agent skill 评测做成三层开源流水线](https://github.com/NVIDIA/SkillEvaluator)** — 新进入本账本 Trending，1,685 stars、122 stars/day，Apache-2.0，最新 v0.9.0。它把静态安全与结构检查、语义去重、安装/未安装 skill 的隔离 A/B Agent 运行串成 CI；NVIDIA 还披露 OpenClaw 正在 ClawHub 官方组织中试点 Tier 3 评测。官方 300+ skills 汇总结果显示平均 Skill Lift 为 +31 分，但 85% skill 仅单次尝试、未报告置信区间，且自动生成 eval 可能把 skill 自身偏见带进评分，因此更适合做发布门槛与回归信号，而不是质量真理机。

### 开源 & 社区

- **[NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator)** — 覆盖 skill schema、prompt injection/数据外泄、secrets/PII、license、重复内容，以及在 Harbor sandbox 中用同一模型、任务和评分标准做 with/without-skill 对照。优点是把“这个 skill 到底有没有帮到 Agent”变成可回归的制品；主要风险是项目仍标注 Experimental、无 SLA，Tier 2/3 需要模型与 sandbox 成本，单次运行方差和自动生成评测集可能造成虚假精确度。
- **[Tencent/LoopForge](https://github.com/Tencent/LoopForge)** — 今日首次观察进入 Trending，1,495 stars、423 stars/day，最新 v0.3.8。它在 Codex、Claude Code、Cursor、OpenCode、Pi 等 coding CLI 外围增加可版本化 SOP、独立角色、脚本节点、人工审批、Docker sandbox、制品与成本追踪，也提供可直接装进本地 coding assistant 的流程。项目仍是早期 0.x；默认平台把 Docker socket 暴露给 sandbox、新安装监听 `0.0.0.0:8090`，且面向“受信任团队”而非不可信多租户，部署前必须收紧网络、注册、仓库与凭据边界。README 声明 MIT，但 GitHub API 许可证元数据暂为 NOASSERTION。
- **72 小时观察候选：[ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui)** — Agent 与前端交互协议，17,868 stars、355 stars/day，11 月 13 日有新 release；成熟采用度不错，但协议/API 面大、约 593 open issues，需确认新版本是否形成相对历史的重大能力增量。
- **72 小时观察候选：[tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)** — 投资与交易分析 skills，5,562 stars、706 stars/day、MIT；热度较强但无正式 GitHub release，金融数据、提示词来源和把分析误当交易建议的风险需要先审计。

## 🔧 跟我们相关的

- 优先把 **SkillEvaluator Tier 1** 作为 OpenClaw skill 发布前的补充检查试跑，再用少量人工编写的正例、负例和越权例做 Tier 3；不要直接采用自动生成 eval 的总分。
- **LoopForge** 的 SOP、独立 reviewer、脚本验收与人工 gate 值得参考，但现阶段只适合在无生产凭据的隔离环境做架构对比；尤其不要把可访问宿主 Docker socket 的默认部署直接暴露公网。
- 对 AI 辅助科研统一保留三层证据标签：供应商/作者声明、公开预印本与工件、独立专家复核；今天的格点标准模型工作只到前两层。
