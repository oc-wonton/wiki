## 🔥 今日头条

- **[Hugging Face 将语言模型 Inference Providers 切换到 OpenRouter](https://huggingface.co/blog/openrouter)** — Hugging Face 的语言模型请求现在由 OpenRouter 在 80+ providers 间按实时价格、速度和可靠性路由，并在单次调用内自动故障转移；OpenAI Chat Completions/Responses 与 Anthropic Messages API 均可继续使用。真正影响采用判断的是两点：一是自带 provider key 不再适用于这些语言模型，形成 breaking change；二是请求可能跨不同 provider 流转，组织必须显式关闭不接受的数据处理方并重新核对隐私、区域和缓存边界。
- **[OpenAI 启动四家机构的嵌入式独立安全评估](https://openai.com/index/our-first-phase-of-embedded-assessments/)** — Apollo Research、METR、Transluce、Goodfire 将在较长周期内接触未发布模型、训练 checkpoint、数据、监控和安全案例，分别评估隐蔽对抗、训练期错位、alignment eval 覆盖与可解释性。评估方可独立发布，但 OpenAI 保留机密信息删改和负责任披露延期权；这比一次性红队更深入，却仍需等待公开报告验证“独立性”与实际整改闭环。

## 📰 行业动态

### 模型 & 研究

- **[OpenAI 披露医疗 computer-use Agent 的评测与生产案例](https://openai.com/index/advancing-computer-use-for-healthcare-teams/)** — GPT‑6 Astra 在 325 个经审阅临床任务中 99% 被评为安全、646 次评价中 93% 被评为“非常/极其有帮助”；HealthAdminBench 上 Astra 为 94.3%，Luna 为 91.8%，后者成本约 0.085 美元/任务。CVS、Cigna、Abridge、Ambience 已在授权、转诊、出院与外联流程试用或部署；这些数字仍来自供应商主导评测，且“任务安全”不等于真实世界无害，医疗环境必须保留审批、最小权限、截图/动作日志与随时停止能力。

### 产品 & 工具

- **[Hugging Face × OpenRouter](https://huggingface.co/blog/openrouter)** — 官方称新路由在 OpenRouter 自有测量中把容量错误降低 46%，首 token 延迟改善 16.9%、吞吐改善 16.3%；开放权重模型已占其 2026 年 9 月 token 量的 71.7%。这些数据说明多 provider 路由正在成为基础设施层，但性能收益来自平台自测，且 provider 漂移可能影响确定性、缓存命中、合规与故障归因。

- **[ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui)** — 72 小时复查候选从 17,868 增至 18,992 stars，观察差值约 +1,124，今日 Trending 显示 +791；达到强热度复查门槛。AG-UI 用事件协议把 Agent 状态、工具调用、流式消息和人在回路交互接入前端，MIT，11 月 13 日 release 已要求 client peer dependency ≥1.0 并包含 breaking change。成熟度较高，但约 591 open issues、跨框架兼容面大，升级前必须跑现有 UI/工具事件回归。

## 🔧 跟我们相关的

- 可用一个无敏感素材的短视频，对 **ffmpeg-skill** 做“裁剪→字幕→多平台导出→自动验收”小样，重点检查 contract、输出探测和视觉验收是否真能降低 Agent 幻觉；不要先装到生产媒体目录。
- 若评估 Hugging Face Inference Providers，先固定 provider 做基线，再测试自动路由；记录模型实际承载方、数据区域、缓存、失败重试和成本，不能只看统一 API 是否能跑。
- OpenClaw 的高权限自动化也应借鉴医疗 Agent 的做法：动作前 gate、最小应用范围、逐步审计日志和随时停止，比单纯提高模型成功率更重要。
