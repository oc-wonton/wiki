## 🔥 今日头条

- **[Google 发布 Gemini 4 Neon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)** — Neon 面向高频复杂 Coding Agent、知识工作和科研流程，提供 100 万 token 上下文，定价为输入 $3/M、输出 $15/M，缓存输入折扣 95%。Google 称它在 Terminal-Bench 4.1 为 65.2%、FrontierCode 2.0 为 46.2%，在 Antigravity harness 下 SWE-sweep 从 12.8% 升至 39.0%；这再次说明“模型 × harness”才是实际能力单元。多数安全、成本和能力数字来自官方或第三方榜单，仍需用私有任务复测。
- **[OpenAI 公布 Agent 对内部 AI 研发加速的最新量化报告](https://openai.com/index/research-acceleration-jagged-frontier/)** — 研究人员平均每天的 Agent 工作量从 0.5 个工作日升至 5.7 个，超过三分之二研究人员的日峰值并发至少 4 个 Agent；但零人工干预成功率呈明显“锯齿”：监控实验 79%、技术问答 72%，推理/服务代码仅 25%，构建 eval、RL 和 Agent 环境为 29%。报告来自 OpenAI 内部分类与自报数据，不能外推为普遍生产力结论，但它把“规模化并发”和“人类验收仍是瓶颈”同时量化了。

## 📰 行业动态

### 模型 & 研究

- **[Gemini 4 Neon](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-neon/)** — Google 将其定位在 Carbon 的深度与 Hydrogen 的速度之间，并提供四档 thinking。官方称高档位单任务成本比 Carbon 低 32%，在 Agent Arena、专业知识工作和 Cyber benchmark 上进入前列；Cyber 版本先向 Fairwind 可信防御者开放。高权限使用仍要分开验证基础模型、harness、安全分类器和真实成本。
- **[Genie 4 首次进入 Project Genie](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/genie-4-now-available-project-genie/)** — Google AI Ultra 用户可在浏览器中实时生成、探索并用中途提示修改交互世界，Genie 4 新增随场景变化的原生音频；Genie 3 则把单次世界延长到 3 分钟并支持串联。Google 明确承认摄像机延迟、复杂物理、音频精度和长期场景持久性仍未解决，因此更适合创意原型，不是稳定仿真环境。

### 产品 & 工具

- **[Claude Platform 推出 linked billing beta](https://claude.com/resources/articles/linked-billing-on-claude-platform)** — 第三方 Agent/自动化平台可让客户连接自己的 Anthropic 组织并直接承担 API 费用，不再交出 API key；客户可按平台设月度限额并随时解绑。不过请求实际运行在第三方平台的组织中，客户侧 IP allowlist、加密密钥和数据保留策略并不会继承，账单隔离不等于数据隔离。
- **[Claude Code 团队公开 Agent verification 方法](https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/)** — 其代码约 90% 由 Claude 编写和审查，团队优先投入 E2E、property 和 differential tests；失败三轮后转人工，变更不能修改评判自己的规则，新 gate 先 observe 再 enforce，并用历史事故与回滚持续校准 reviewer。核心不是“多加一个更贵的 reviewer”，而是让每次交付都有独立、不可自改、可重复运行的证据。
- **[OpenAI 公开 Codex sandbox 设计](https://openai.com/index/inside-the-codex-sandbox/)** — 默认 workspace profile 允许工作区写入、保护 `.git`/`.codex`、广泛读取本机文件并关闭网络；网络按域代理允许时，DNS 解析也在授权后发生。文章同时明确 stdio MCP server 默认不自动进入 sandbox，需要用户用 `codex sandbox` 包装。广泛只读仍可能读到密钥，忽略目录和 MCP 进程也可成为逃逸面，sandbox 不能替代最小权限和独立监控。
- **[Transformers 实验在 32GB Mac 上流式运行 180B MoE](https://huggingface.co/blog/moe-expert-streaming)** — 实验把路由到的专家从 SSD 流式载入有界缓存，让 Qwen3.8-Flash-Next 在 M5/32GB 上约 14 tok/s，短解码只比 Strata 慢约 6%，4K prefill 约 228 tok/s。实现仍依赖待合并的 Transformers PR、3-bit 专家量化和模型专用 Metal kernel，转换约 5 小时，属于可复现实验而非稳定产品。

## 🔧 跟我们相关的

- 用同一组 OpenClaw/OMP 私有任务测试 **Gemini 4 Neon**：记录成功率、工具步数、缓存命中、失败是否显式、每次成功成本；重点比较裸 API 与 Agent harness，而不是只看总榜。
- 把 Claude Code 的 verification 方法压成最小可执行规则：交付前必须运行真实系统；评判规则从基线分支读取；同一失败最多自动修三轮；新 gate 先 observe；历史事故才能进入长期 checklist。
- **CLI-Anything** 只挑一个低权限、无凭据的 harness 做隔离试验，先看生成代码、安装脚本、遥测、网络和文件权限，再决定是否纳入 OpenClaw skill 生态。
- 对 linked billing 保持清醒：它解决“谁付钱、是否交 API key”，不自动继承客户组织的数据治理；接入第三方平台前仍要审查请求落点、日志和数据保留。

## 💡 一句话观点

> 今天最清晰的信号是：Agent 能力正在从“模型分数”迁移到“模型 × harness × verifier × 权限边界”，真正可扩展的系统不是最会写，而是最会证明自己写对、并在证明失败时停下来。
