    🤖 AI 日报 — 2026-11-21¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Inkling 2 Mini 把循环 Transformer 做成约 20GB 的本地多模态 Agent 模型 — Thinking Machines Lab 开放 26.4B 总参数、约 3.4B 激活参数的权重；中间 12 层重复三次，在不增加存储层数的情况下增加每 token 串行计算。官方称它在 DeepSWE v1.1 达 48.2%、约 20GB 可在高配笔记本离线运行；同时发布可变循环研究版。关键风险也被项目方直接点出：循环让一部分推理发生在不可见的内部计算中，可能削弱 chain-of-thought 监控；多数能力分数仍是官方评测，需独立复现。该发布在 Hacker News 约 621 points / 102 comments。
    • Frostbite：AI 从 ISA、编译器一路协同设计到 GDS 的新 CPU 架构 — Architect Labs 称 Agent swarm 在 25 个工作负载（含 15 个 held-out）上设计并验证 interaction-net CPU，相对同工艺双发射顺序核取得几何平均 4.59× 性能功耗比，并以形式化 ASL 合约下沉到 80 万行以上 Lean 约束。真正值得关注的是“机器可检验规格作为多 Agent 唯一真相源”的工程方法，而非先接受性能结论：结果仍是 7nm pre-silicon 综合/GDS、没有实硅，比较对象和工作负载范围有限，核心 RTL/ASL 也未公开。HN 约 618 points / 322 comments。

    📰 行业动态¶

    模型 & 研究¶

    • Inkling 2 Mini — 24 个物理层通过中间层三次循环形成 48 次 layer visit，支持文本与图像、最长 1M context，并提供 Transformers、llama.cpp、MLX、SGLang 的首日支持。它在知识密集任务上并不因增加循环次数而获得更多事实知识，多轮约束执行也落后于 Qwen3.8-27B；因此更适合先评测本地 coding/search Agent，而不是把“循环”理解成全面能力升级。
    • OpenAI 发布 MedChemBench — 99 道药物化学问题来自 117 篇论文和专利、覆盖 761 个分子结构，分别检查结构重建、证据解释、候选排序和性质预测。官方结果显示较新模型在结构重建上很强，但候选选择与数值性质预测只取得约一半可用分；OpenAI 也明确承认无法排除训练数据接触，且历史证据推理不能证明模型能发现新药。这是“把漂亮总分拆成实验决策能力”的好例子，不是药物研发自动化已成熟的证据。

    产品 & 工具¶

    • Hugging Face 用 harness-specific RL adapter 同时提高 Coding Agent 成功率并降低 token — 在冻结 Qwen3.8-27B 主权重后，分别为 Pi、Hermes Agent、OpenCode 训练 LoRA；Pi 的 Terminal-Bench 2.1 从 39% 提到 55%，平均 token 从 2.9K 降到 1.5K，并公开任务、adapter、GGUF 和训练 recipe。更重要的是数据管线：1,127 个候选任务先做 oracle、空操作、错误答案和确定性检查，再筛出 171 个“不是全会、也不是全不会”的有效 RL 任务。局限是分数来自同一团队的训练/评测设置，且 tool-efficiency 奖励可能把“少调用工具”误学成捷径，迁移到 OpenClaw 前需在自有任务上做独立 holdout。

    开源 & 社区¶

    • zhouxiaoka/autoclip — 今日首次进入本账本 GitHub Trending：12,188 stars、2,016 forks，MIT，最新正式版 v1.5.8。它把长播客、访谈和课程自动切成多平台短视频，桌面端、CLI、MCP 共用本地剪辑链，可用本地 Whisper/Ollama，也可接云端分析与转写。项目有真实样例、成本记录和明确隐私说明，但仍是个人维护；预编译包、FFmpeg/yt-dlp 供应链、模型凭据、云端音频/画面出站和自动投稿账号权限都应先隔离验证。
    • mvanhorn/last30days-skill v4.4.0 — 这是已推送项目的独立新事件：新增面向职业人士的 person research（employer / LinkedIn / email），同时修复 webhook 凭据输出、私有 drill context 进入公开 brief、研究数据库/归档保护、浏览器 consent 和 X 登录检查等隐私边界。新能力扩大个人信息处理面，安全修复又改变了采用判断，故使用 release URL 复报；仍应固定版本、禁用不需要的数据源，并用非敏感样例核验出站与发布内容。
    • 72 小时观察：jingyaogong/minimind — 首次观察进入 Trending，67,691 stars、8,855 forks、Apache-2.0；以原生 PyTorch 覆盖从预训练到 Agentic RL 的教学链。采用度高，但 v2 release 已是 2025 年，当前主线的 MiniMind-3 更新也早于本窗口；它更像可复现课程而非生产模型，先观察本轮热度是否对应新的工程增量。
    • 72 小时观察：firecrawl/firecrawl — 首次以稳定 key 进入本账本 Trending，205,275 stars、10,744 forks、AGPL-3.0；新 README 强调单二进制 Firecrawl Local、MCP 和本地 API。成熟度高，但最新 GitHub release 仍是 6 月的 v2.11.0，且默认本地抓取失败时可能回退云端；在确认本轮上榜是否对应正式 release、独立评测与清晰离线边界前暂不重复包装旧能力。
    • 已推送项目复查： elementalsouls/Claude-BugHunter 从昨日 12,532 增至 14,277（观察差值 +1,745，页面 +1,622/day），未达自首次推送 3 倍或单日约 +5,000；mjmirza/app-store-compliance 从 1,843 增至 2,747（+904，页面 +869/day），无新 major release；Tracer-Cloud/opensre 从 13,125 增至 13,614（+489），新日更 patch release 没有实质 changelog；三者均不满足独立事件复报门槛。

    🔧 跟我们相关的¶

    • 优先复现 harness adapter 的方法而不是照搬权重：从 OpenClaw/OMP 的真实任务抽取小型训练集与完全隔离的 holdout，先验证“成功率提升”没有来自 verifier 漏洞或减少必要工具调用。
    • 把 Frostbite 的可取部分落到软件 Agent：规格、实现、验证分别可执行，且被评对象不能修改自己的 gate；性能宣称等到公开工件或独立复现再升级判断。
    • 若试 AutoClip，只用公开素材、本地转写和本地模型跑一条样例；先关闭匿名统计与自动投稿，不把平台账号或真实私有音视频交给首次评测环境。
    • Inkling 2 Mini 值得进入本地 Agent 模型候选，但先测真实 OpenClaw tool-use、长任务恢复、显存/内存和每任务能耗；不要只看作者 benchmark。

    💡 一句话观点¶

    今天最强的共同信号不是“AI 自己完成了更多”，而是把 Agent 的自由度包在可验证任务、不可自改的规则和可复现工件里；性能数字可以晚点信，验证结构必须先有。
