## 🔥 今日头条

- **[Claude 让 MCP server 原生交付 Skills、长任务与中途审批](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more)** — Skills over MCP 进入公开 beta，服务器可把工具与按需加载的操作指南一起发布；Tasks 和 Elicitation 已 GA，让服务器在后台运行完整 Agent loop，并在付费、删除数据等节点暂停请求用户确认。对 OpenClaw 最关键的不是“又多一种 skill 分发”，而是 MCP 正从工具调用协议扩展成带委派、等待、审批和文件交换的 Agent 协作层；但远端 skill 自动更新、服务器权限和供应链仍需独立审计。
- **[OpenAI 披露 GPT‑6 的通用蛋白设计能力，并给出湿实验结果](https://openai.com/index/gpt-6-models-demonstrate-intrinsic-protein-design-capabilities/)** — GPT‑6.2 仅靠推理和通用代码工具生成蛋白结构与序列；项目方与 Onava 对 5 个目标测试 322 个 minibinder，35 个（10.9%）出现结合信号，抗体片段重设计也保留较高结合率。结果说明通用模型开始跨入专业科学设计，但候选筛选仍使用专用模型，完整结构预测仍是弱项，且 benchmark 与实验主要来自项目方，不能把“出现结合”直接等同于药物有效或安全。

## 📰 行业动态

### 模型 & 研究

- **[Ternary Bonsai 2.5 27B 强化本地 Agent 编码与多轮工具调用](https://prismml.com/news/bonsai-2-5-27b)** — 基于 Qwen3.8 27B 的三值压缩模型保持约 5.9GB，Apache-2.0 权重覆盖 llama.cpp 与 MLX。项目方报告 SWE-bench Verified 75.6、Terminal-Bench 2.1 60.1、AppWorld 90.5，并称 RTX 4090 上配合 MTP 可达 204 tok/s；HN 约 311 points / 107 comments。它是高信号的本地私有 Agent 候选，但所有核心性能仍为厂商自测，实际质量、MTP 条件和长任务稳定性需独立验证。
- **[OpenAI 用 Astra/Codex 在公开天文数据中找到待确认系外行星候选](https://openai.com/index/searching-for-distant-planets-with-astra/)** — 两名业余研究者分别分析约 10 万和 1,900 万颗恒星；其中两个 Kepler 信号被 SETI Institute 的独立搜索复现，另一个 TESS 候选已进入进一步分析队列。候选可能仍需数月或数年确认，但案例显示 Coding Agent 已能帮助非专业团队组合公开算法、构建搜索管线并产生可由专家继续验证的科学线索。

### 产品 & 工具

- **[Claude Artifacts 可安装为 Mac/Windows 桌面应用](https://claude.com/resources/articles/install-as-app)** — beta 支持独立窗口、通知、菜单栏/托盘和 connectors；权限分为浏览器级、受控 App permissions、以及可运行程序和读写/删除文件的 Full computer access。每次 artifact 更新后会重新请求权限是正确设计，但第三方网页内容可变化而不触发重新授权，且 Anthropic 不预审应用；现阶段应把全盘访问限定在自建或组织内应用。
- **MCP 新能力改变了插件边界。** Skills over MCP 默认面向 Pro/Max/Ultra，Tasks 与 Elicitation 已可用于后台工作和人工 gate，File Uploads 将让 PDF、表格和图片不经过上下文窗口直接传给服务器。更强的协议能力也意味着更大的远端信任面：skill 更新、文件内容、费用审批和破坏性动作都要在客户端保留明确可见的授权与审计记录。
