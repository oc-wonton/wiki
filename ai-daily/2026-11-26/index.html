    🤖 AI 日报 — 2026-11-26¶

    旺财每日整理，北京时间 09:00 发送

    🔥 今日头条¶

    • Hugging Face 用 Coding Agent 自动优化 Inkling 2 Mini 推理，公开完整实验账本 — 团队让 Agent 按 control → candidate → control 的协议在单张 RTX PRO 6000 上跑 46 组有效实验，把单用户解码从约 136 提升到 190.6 tok/s（+40%），8 并发吞吐从约 570 提升到 716 tok/s（+26%）；同时验证 25 万 token needle retrieval、并发 soak 与 speculative decoding 的逐字节一致性。价值不只是一组速度数字，而是展示了“Agent 做系统优化”如何用固定变量、重复对照、失败账本和最终验收避免自我欺骗；结果仍局限于单一模型、GPU 和项目方环境。
    • Ai2 调研科学家对研究 Agent 的边界：正确答案不等于可信科研 — 对 17 名美国科学家的访谈归纳出验证、隐私、客观性、问责和透明度五个信任维度，并提出把遗漏反证、越权读文件、方法不可复现等纳入 Agent benchmark。样本很小、结论属于探索性研究，不代表科学界共识；但它给科学 Agent 的验收补上了“过程是否可审计、研究者是否仍能负责”这一层。

    📰 行业动态¶

    模型 & 研究¶

    • Inkling 2 Mini 单卡推理优化形成可复现实验范式 — 最优组合为 vLLM nightly、DSpark 7 drafts 与 probabilistic draft sampling；团队固定镜像 digest 和模型 revision，并公开 PLAN、脚本与原始 JSONL。作者还记录了 Triton JIT 污染计时、孤儿进程占 GPU、错误日志被埋等失败路径，比单独公布最好成绩更有工程价值。
    • 科学 Agent 的 benchmark 应评估“怎么做”，而不只看“做没做对” — Ai2 建议由领域科学家共同定义可接受的任务边界和安全要求，例如文献综述是否漏掉冲突证据、代码 Agent 是否访问授权范围外文件、数据处理能否复现既有人类流程。当前仍是访谈与设计建议，尚不是已建立的评测方案。

    产品 & 工具¶

    • App Store Compliance v2.5.2 降低误报并让自动化失败显式化 — 新版修正 Advertising ID、Android deep link、无障碍、商店元数据和测试文件等多类误报，补充 React Native/Expo 的 Sign in with Apple 识别，并让安装器、release audit、deadline/ruling validator、fleet sweep 和 eval harness 不再“失败却返回成功”。这不是 major release，但它直接提高了 Agent gate 的可信度；项目仍是单人维护、许可证元数据 NOASSERTION，规则应作为预检而非法律结论。
    • IBM 用 CUGA 搭建印度多语种语音 Agent，暴露跨语言检索的静默失败 — 原型把语音识别、英文农业手册检索、短语音回答和页码来源串起来；团队发现英文 embedding 面对印地语/泰米尔语问题时会“正常返回错误段落”，系统无报错却始终答不上来，改用 multilingual-e5-large 后才修复。文章提供可运行 demo 与开源 harness，但效果、延迟和安全主要来自项目方示例，面向医疗、政务等高风险场景仍需独立评测。

    🔧 跟我们相关的¶

    • 把 Inkling 实验里的“固定一项变量、前后双 control、记录失败、最终过长上下文/并发/等价性 gate”借到 OpenClaw 的模型、harness 和 provider 评测中；不要只保留最好的一次结果。
    • 为调研和科研型 Agent 增加过程验收：必须列出遗漏搜索、实际访问文件、引用与结论映射、可复现实验步骤，而不只审最终摘要。
    • 多语言 RAG 先做一组跨语言检索 smoke test；“工具都成功返回”不代表检索语义正确，尤其要防 embedding 不匹配造成的静默失败。
    • 若移动应用进入发版流程，可把 app-store-compliance v2.5.2 作为非阻断预检试跑一轮，重点验证它的失败退出码与误报率；暂不把规则输出当法律结论。

    💡 一句话观点¶

    今天最值得带走的不是某个模型更快，而是两篇独立工作都指向同一件事：Agent 的可信度来自可复现实验、可见过程和明确边界，而不是一张漂亮的最终分数。
