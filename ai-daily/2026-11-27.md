## 🔥 今日头条

- **[Hugging Face 给多 Agent 协作加上“等预算对照”：先证明沟通真的有用](https://huggingface.co/blog/training-swarms)** — 四个共享 Qwen3-0.6B 权重、各持私有信息的 Agent 经团队奖励训练后，训练成功率从 6.6% 升至 82.3%，每队生成 token 约降 37%；未训练团队即使用 best-of-8、花约 13 倍 token，也只解出 37.5%。文章最重要的不是“蜂群更强”，而是明确要求把协作与独立重试放在相同预算下比较；当前任务刻意要求信息交换，仍不能证明一般任务上的多 Agent 优势，结果也主要来自作者实验。
- **[NVIDIA 开放 Nemotron 3.5 Parse 的近 1900 万条合成数据、微调 recipe 与验证奖励](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)** — 三套数据覆盖约 998 万图表、100 万表格和 790 万多语种 OCR 页面；匹配实验中，GRPO 将循环输出页面从 126 降至 29、触及 9000-token 上限的页面从 185 降至 35。DFlash2 在单张 H200 上把低并发吞吐提高 7.62 倍、高并发提高 1.52 倍，但这些性能与质量数字仍主要来自 NVIDIA 的特定硬件和合成分布。

## 📰 行业动态

### 模型 & 研究

- **[多 Agent 训练应先过“独立重试 + 等 token 预算”基线](https://huggingface.co/blog/training-swarms)** — Hugging Face 的首个教程用团队共享 reward、消息工具和可验证排序任务训练四 Agent 通信；75 步后 held-out 为 26/32，文章也坦承该任务单 Agent 本来就无法完成，因此后续才会进入真正可与单 Agent 公平比较的任务。可复现实例约需两张 H200、5 小时和约 50 美元，原始大实验则用了 1 张训练卡与 7 张 rollout 卡。
- **[Nemotron 3.5 Parse 把文档抽取从“开模型”扩展为“数据 + verifier + 训练链”](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)** — 开放内容不仅包括模型，还包括图表/表格/OCR 数据生成说明、SFT/GRPO recipe、表格与图表 reward components，以及双/三阶段重解析路径。对 RAG 和 Agent 更实用的增量，是可以针对自有表单定义 schema 与 verifier；但牙科表单 96.58% 的结果来自同一合成生成器分布，不能直接外推到真实脏数据。

### 产品 & 工具

- **[llama.cpp 与 AMD 上线可追溯的 Ryzen/Radeon 基准面板](https://huggingface.co/blog/ggml-org/llamacpp-amd-bench)** — 面板公开每周 workflow 与 JSONL 原始结果，可按硬件、模型、量化和 llama.cpp build 比较 PP512、TG128 及上下文增长后的速度。目前仅覆盖 Radeon 8060S 与 AI Pro R9700S，且固定短 workload 不等于真实 Agent 长上下文性能；价值在于以后可定位某次 build、kernel 或量化是否带来回归，而不是只看一次性宣传数字。
