# Oh My Pi 同名包误装

## 发生了什么

用户要求安装 Oh My Pi。仅根据 npm 搜索结果与包 README，将无关的 `oh-my-pi` 扩展误判为目标；真正的项目是 `can1357/oh-my-pi`，npm 包为 `@oh-my-pi/pi-coding-agent`，CLI 为 `omp`。

## 根因

- 只验证了包名和描述，没有先确认用户所指产品的官方仓库。
- 没有交叉核对维护者、CLI 名称、官网和项目定位。
- 同名包的 README 自称 Oh My Pi，造成错误的高置信判断。

## 正确做法

安装名称可能重名的软件前，至少核对四项：

1. 官方仓库与维护者。
2. 官方网站或 Release 页面。
3. 正式包名和 CLI 命令。
4. 产品定位是否与用户语境一致。

若搜索结果冲突，先向用户说明候选项，或继续查证，不能直接安装。

## 修复

- 卸载错误的 `npm:oh-my-pi` Pi 扩展。
- 安装官方 `@oh-my-pi/pi-coding-agent`。
- 验证 `omp --version` 和首次配置界面。
